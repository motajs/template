# 6.12.1 帧缓冲对象概念

之前我们讲到，当 `WebGL2` 渲染时，需要先渲染到帧缓冲上，然后把帧缓冲交给屏幕显示。那如果我们把帧缓冲截获，不让它渲染到屏幕上，而是渲染到一个纹理上呢？

我们将 `WebGL2` 渲染到纹理上，这一步是通过帧缓冲对象 Frame Buffer Object（简称 FBO）实现的。

## 创建 FBO

我们使用 `gl.createFramebuffer` 创建帧缓冲对象，注意这里的 `createFramebuffer` 中 `Framebuffer` 的 `b` 不大写。

```TypeScript
function createFramebuffer(): WebGLFramebuffer;
```

示例如下：

```TypeScript
const fb = gl.createFramebuffer();
```

## 绑定 FBO

操作 `FBO` 的方式与缓冲区类似，都遵循先绑定再操作的模式。

首先我们需要使用 `gl.bindFramebuffer` 将 `FBO` 绑定：

```TypeScript
function bindFramebuffer(target: GLenum, framebuffer: WebGLFramebuffer | null): void
```

其中第一项是要绑定至哪个缓冲区，一般我们填写 `gl.FRAMEBUFFER`。

第二个参数是要绑定的 `FBO`，填写 `null` 时表示取消绑定。

我们需要将刚刚创建的缓冲区绑定：

```TypeScript
gl.bindFramebuffer(gl.FRAMEBUFFER, fb);
```

这是我们操作的就是我们绑定的缓冲区了，而且渲染时也是渲染至此 `FBO`，而不是画布本身。因此这时候你去渲染的话将什么都得不到。

## 配置 FBO 渲染至纹理

操作 `FBO`，并配置为渲染至纹理使用 `gl.framebufferTexture2D` 方法：

```TypeScript
function framebufferTexture2D(
    target: GLenum,
    attachment: GLenum,
    texTarget: GLenum,
    texture: WebGLTexture,
    level: number
): void;
```

- `target`：要操作的 `FBO` 缓冲区，一般填写 `gl.FRAMEBUFFER`。
- `attachment`：要将什么内容渲染到 `FBO`，可以填写 `gl.COLOR_ATTACHMENT0` 表示颜色内容，也可以填写 `gl.DEPTH_ATTACHMENT` 表示深度内容等。
- `texTarget`：表示将内容渲染至哪个纹理，如果使用二维纹理，填写 `gl.TEXTURE_2D`。
- `texture`：表示渲染至的纹理对象。
- `level`：这一项只能填 0。

我们需要将颜色渲染至纹理，渲染至 `gl.TEXTURE_2D` 纹理。因此：

```TypeScript
// 创建纹理
const frameTexture = gl.createTexture();
gl.framebufferTexture2D(gl.FRAMEBUFFER, gl.COLOR_ATTACHMENT0, gl.TEXTURE_2D, frameTexture, 0);
```

# 6.12.2 初始化纹理

此时我们并不能直接开始渲染，因为现在纹理没有任何内容，此时它的大小为 0，将一个大小不一致的东西渲染到纹理当然会有问题。因此我们需要预先给纹理分配内存。

这一操作使用 `gl.texImage2D` 的这个重载：

```TypeScript
function texImage2D(
    target: GLenum,
    level: number,
    internalFormat: GLenum,
    width: number,
    height: number,
    border: number,
    format: GLenum,
    type: GLenum,
    pixels: TypedArray
): void;
```

- `target` `level` `internalFormat` `format` `type`：这些前面讲过，不再讲了。
- `width` `height`：给纹理指定大小。因为我们需要使用一维的 `TypedArray`，不指定宽高的话 `WebGL2` 没办法知道纹理应该多大。
- `border`：这一项必须填 0。
- `pixels`：`TypedArray` 组成的颜色信息。

我们初始化的时候不需要提供颜色信息，初始化纹理大小为 `512*512`，因此：

```TypeScript
gl.bindTexture(gl.TEXTURE_2D, frameTexture); // 记得绑定纹理
gl.texImage2D(
    gl.TEXTURE_2D, 0, gl.RGBA, 512, 512, 0, gl.RGBA, gl.UNSIGNED_SHORT, 
    // 使用 Uint8Array 类型化数组，长度为面积*4，因为有 RGBA 四个通道
    new Uint8Array(512 * 512 * 4)
);
// 配置纹理信息
gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MAG_FILTER, gl.LINEAR);
gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MIN_FILTER, gl.LINEAR);
gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_WRAP_S, gl.CLAMP_TO_EDGE);
gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_WRAP_T, gl.CLAMP_TO_EDGE);
```

# 6.12.3 着色器

我们需要画一个正方体，同时把贴图贴上去，因此我们对 6.10 节的着色器稍加修改即可。

## 顶点着色器

需要编写 `u_transform` 变量，同时接收 `a_texCoord`，输出 `v_texCoord`：

```OpenGL Shading Language
#version 300 es
precision highp float;

in vec4 a_position;
in vec2 a_texCoord;

uniform mat4 u_transform;

out vec2 v_texCoord;

void main() {
  v_texCoord = a_texCoord;
  gl_Position = u_transform * a_position;
}
```

## 片段着色器

接收 `v_texCoord` 并读取纹理：

```OpenGL Shading Language
#version 300 es
precision highp float;

in vec2 v_texCoord;
out vec4 outColor;

uniform sampler2D u_sampler;

void main() {
  outColor = texture(u_sampler, v_texCoord);
}
```

# 6.12.5 图片加载

我们不再在 `drawScene` 里面传递纹理，因为这样的话会每帧传递一次，性能会显著下降。我们只需要在图片加载完毕的时候传递纹理就可以了：

```TypeScript
const imgSrc = 'https://cdn.jsdelivr.net/gh/unanmed/h5-programming-training/img/5.11.webp';
const img = new Image();
img.src = imgSrc;
img.crossOrigin = '';

const texture = gl.createTexture();

img.addEventListener('load', () => {
  gl.activeTexture(gl.TEXTURE0);
  gl.bindTexture(gl.TEXTURE_2D, texture);
  gl.texImage2D(gl.TEXTURE_2D, 0, gl.RGBA, gl.RGBA, gl.UNSIGNED_BYTE, img);
  
  // 设置纹理参数
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MAG_FILTER, gl.LINEAR);
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MIN_FILTER, gl.LINEAR);
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_WRAP_S, gl.CLAMP_TO_EDGE);
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_WRAP_T, gl.CLAMP_TO_EDGE);
  
  gl.uniform1i(sampler, 0);
  
  // 调用 drawScene
  requestAnimationFrame(drawScene);
});
```

# 6.12.6 渲染行为

为了之后叙述方便，并消除歧义，我们会使用一个单独的名词 draw call，它表示调用一次渲染函数 `gl.drawArrays` 等。

为了实现目标效果，我们需要两次 draw call，首先将一个贴满图片的正方体渲染到 `FBO`，然后再把 `FBO` 作为纹理渲染到正方形上，作为最终渲染结果。

## 第一次渲染

我们需要先设定视口，将视口大小与纹理大小匹配，视口大小可以比画布本身更大：

```TypeScript
gl.viewport(0, 0, 512, 512);
```

然后我们清空缓冲区：

```TypeScript
gl.clearColor(0.4, 1, 1, 1);
gl.clearDepth(1);
gl.clear(gl.COLOR_BUFFER_BIT | gl.DEPTH_BUFFER_BIT);
```

接下来我们需要绑定 `FBO`，将要渲染至的 `FBO` 绑定到 `gl.FRAMEBUFFER`，并把要渲染至的纹理绑定至 `gl.TEXTURE_2D`：

```TypeScript
gl.bindTexture(gl.TEXTURE_2D, texture);
gl.bindFramebuffer(gl.FRAMEBUFFER, frameBuffer);
```

 最后执行 draw call：

```TypeScript
gl.drawArrays(gl.TRIANGLES, 0, array.length / 5);
```

## 第二次渲染

我们需要设置视口为画布大小：

```TypeScript
gl.viewport(0, 0, canvas.width, canvas.height);
```

取消 `FBO` 绑定并绑定纹理为刚刚 `FBO` 渲染至的纹理：

```TypeScript
gl.bindTexture(gl.TEXTURE_2D, frameTexture);
gl.bindFramebuffer(gl.FRAMEBUFFER, null);
```

记得清空缓冲区：

```TypeScript
gl.clearColor(0, 0, 0, 1);
gl.clear(gl.COLOR_BUFFER_BIT | gl.DEPTH_BUFFER_BIT);
```

最后渲染至画面：

```TypeScript
gl.drawArrays(gl.TRIANGLES, 0, array.length / 5);
```

```TypeScript
import { mat4 } from "https://esm.sh/gl-matrix";

const imgSrc = 'https://cdn.jsdelivr.net/gh/unanmed/h5-programming-training/img/5.11.webp';
const img = new Image();
img.src = imgSrc;
img.crossOrigin = '';

// 创建画布
const canvas = document.querySelector("#webgl");
const gl = canvas.getContext("webgl2")!;

//设置画布宽高
canvas.width = 300 * devicePixelRatio;
canvas.height = 300 * devicePixelRatio;

const frameBufferSize = 512;

// 顶点着色器
const vs = /* glsl */ `
`;

// 片段着色器
const fs = /*glsl */ `
`;

// 编译着色器
const vsShader = compileShader(gl.VERTEX_SHADER, vs)
const fsShader = compileShader(gl.FRAGMENT_SHADER, fs);

// 创建程序并编译链接
const program = gl.createProgram();
gl.attachShader(program, vsShader);
gl.attachShader(program, fsShader);
gl.linkProgram(program);

// 如果程序链接失败
if (!gl.getProgramParameter(program, gl.LINK_STATUS)) {
  const info = gl.getProgramInfoLog(program);
  throw new Error(`无法编译 WebGL 程序。\n\n${info}`);
}

// 定义顶点数组和颜色数组
const array = new Float32Array([
  0.5, 0.5, 0.5,    1, 0,
  -0.5, 0.5, 0.5,   0, 0,
  0.5, -0.5, 0.5,   1, 1, // 前面右上角三角形
  0.5, -0.5, 0.5,   1, 1,
  -0.5, 0.5, 0.5,   0, 0,
  -0.5, -0.5, 0.5,  0, 1, // 前面左下角三角形
  
  0.5, 0.5, 0.5,    1, 1,
  0.5, 0.5, -0.5,   1, 0,
  -0.5, 0.5, -0.5,  0, 0, // 上面右后方三角形
  -0.5, 0.5, -0.5,  0, 0,
  -0.5, 0.5, 0.5,   0, 1,
  0.5, 0.5, 0.5,    1, 1, // 上面左前方三角形
  
  -0.5, 0.5, 0.5,   1, 0,
  -0.5, 0.5, -0.5,  0, 0,
  -0.5, -0.5, 0.5,  1, 1, // 左面上前方三角形
  -0.5, -0.5, 0.5,  1, 1,
  -0.5, 0.5, -0.5,  0, 0,
  -0.5, -0.5, -0.5, 0, 1, // 左面下后方三角形
  
  0.5, 0.5, 0.5,    0, 0,
  0.5, -0.5, 0.5,   0, 1,
  0.5, 0.5, -0.5,   1, 0, // 右面上前方三角形
  0.5, 0.5, -0.5,   1, 0,
  0.5, -0.5, 0.5,   0, 1,
  0.5, -0.5, -0.5,  1, 1, // 右面下后方三角形
  
  0.5, -0.5, -0.5,  1, 1,
  0.5, -0.5, 0.5,   1, 0,
  -0.5, -0.5, -0.5, 0, 1, // 下面右后方三角形
  -0.5, -0.5, -0.5, 0, 1,
  0.5, -0.5, 0.5,   1, 0,
  -0.5, -0.5, 0.5,  0, 0, // 下面左前方三角形
  
  0.5, 0.5, -0.5,   0, 0,
  0.5, -0.5, -0.5,  0, 1,
  -0.5, 0.5, -0.5,  1, 0, // 后面右上方三角形
  -0.5, 0.5, -0.5,  1, 0,
  0.5, -0.5, -0.5,  0, 1,
  -0.5, -0.5, -0.5, 1, 1, // 后面左下方三角形

const buffer = gl.createBuffer();
gl.bindBuffer(gl.ARRAY_BUFFER, buffer);
gl.bufferData(gl.ARRAY_BUFFER, array, gl.STATIC_DRAW);

// 传递并启用顶点数组
const position = gl.getAttribLocation(program, 'a_position');
gl.vertexAttribPointer(position, 3, gl.FLOAT, false, 5 * 4, 0);
gl.enableVertexAttribArray(position);

// 传递并启用纹理数组

gl.enableVertexAttribArray(tex);

// 创建纹理对象
const texture = gl.createTexture();

// uniform 变量地址
const sampler = gl.getUniformLocation(program, 'u_sampler');
const transform = gl.getUniformLocation(program, 'u_transform');

// framebuffer
const frameBuffer = gl.createFramebuffer();
const frameTexture = gl.createTexture();
gl.bindTexture(gl.TEXTURE_2D, frameTexture);
gl.bindFramebuffer(gl.FRAMEBUFFER, frameBuffer);
gl.framebufferTexture2D(gl.FRAMEBUFFER, gl.COLOR_ATTACHMENT0, gl.TEXTURE_2D, frameTexture, 0);
// 初始化 fbo 纹理
gl.texImage2D(gl.TEXTURE_2D, 0, gl.RGBA, frameBufferSize, frameBufferSize, 0, gl.RGBA, gl.UNSIGNED_BYTE, new Uint8Array(frameBufferSize * frameBufferSize * 4));
gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MAG_FILTER, gl.LINEAR);
gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MIN_FILTER, gl.LINEAR);
gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_WRAP_S, gl.CLAMP_TO_EDGE);
gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_WRAP_T, gl.CLAMP_TO_EDGE);

// 使用着色器程序
gl.useProgram(program);

// 配置
gl.enable(gl.CULL_FACE);
gl.cullFace(gl.BACK);
gl.enable(gl.DEPTH_TEST);
gl.depthFunc(gl.LESS);

// 创建变换矩阵
const trans = mat4.create();
const model = mat4.create();
const view = mat4.create();
const proj = mat4.create();

mat4.lookAt(view, [0, 3, 4], [0, 0, 0], [0, 1, 0]);
mat4.perspective(proj, Math.PI / 9, 1, 0.1, 10);

// 传递纹理并绘制
const drawScene = (time: number) => {
  // 使用 time 计算角度，与帧率不绑定
  let angle = time / 1000;
  if (time > Math.PI * 2) {
    // 确保范围在 [0, 2*pi] 之间
    const n = Math.floor(time / Math.PI / 2);
    angle -= Math.PI * 2 * n;
  }
  
  mat4.fromYRotation(model, angle);
  
  // 重置并计算变换矩阵
  mat4.identity(trans);
  mat4.multiply(trans, trans, proj);
  mat4.multiply(trans, trans, view);
  mat4.multiply(trans, trans, model);
  
  gl.uniformMatrix4fv(transform, false, trans);
  
  gl.viewport(0, 0, frameBufferSize, frameBufferSize);
  
  // 使用原图作为纹理
  gl.bindTexture(gl.TEXTURE_2D, texture);
  gl.bindFramebuffer(gl.FRAMEBUFFER, frameBuffer);
  
  gl.clearColor(0.4, 1, 1, 1);
  gl.clearDepth(1);
  gl.clear(gl.COLOR_BUFFER_BIT | gl.DEPTH_BUFFER_BIT);

  // 渲染至纹理
  gl.drawArrays(gl.TRIANGLES, 0, array.length / 5);
  
  // 取消 fbo 绑定，使用 fbo 作为纹理
  gl.bindTexture(gl.TEXTURE_2D, frameTexture);
  gl.bindFramebuffer(gl.FRAMEBUFFER, null);
  
  gl.viewport(0, 0, canvas.width, canvas.height);
  
  gl.clearColor(0, 0, 0, 1);
  gl.clear(gl.COLOR_BUFFER_BIT | gl.DEPTH_BUFFER_BIT);
  
  // 渲染至画面
  gl.drawArrays(gl.TRIANGLES, 0, array.length / 5);
  
  requestAnimationFrame(drawScene);
}

img.addEventListener('load', () => {
  gl.activeTexture(gl.TEXTURE0);
  gl.bindTexture(gl.TEXTURE_2D, texture);
  gl.texImage2D(gl.TEXTURE_2D, 0, gl.RGBA, gl.RGBA, gl.UNSIGNED_BYTE, img);
  
  // 设置纹理参数
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MAG_FILTER, gl.LINEAR);
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MIN_FILTER, gl.LINEAR);
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_WRAP_S, gl.CLAMP_TO_EDGE);
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_WRAP_T, gl.CLAMP_TO_EDGE);
  
  gl.uniform1i(sampler, 0);
  
  requestAnimationFrame(drawScene);
});

/**
 * 编译着色器
 * @param type 着色器类型
 * @param source 着色器代码
 */
function compileShader(type: GLenum, source: string): WebGLShader {
  const shader = gl.createShader(type);
  gl.shaderSource(shader, source);
  gl.compileShader(shader);
  
  // 如果编译失败
  if (!gl.getShaderParameter(shader, gl.COMPILE_STATUS)) {
    const info = gl.getShaderInfoLog(shader);
    throw new Error(`无法编译着色器。\n\n${info}`);
  }
  
  return shader;
}
```
