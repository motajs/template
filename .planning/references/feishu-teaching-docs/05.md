# 6.7.1 创建画布

我们使用 300\*300 大小的画布，先编写 `HTML` 内容：

```HTML
<canvas id="webgl" />
```

然后编写 `CSS` 设定画布的尺寸：

```CSS
/* 使用 # 选中指定 id 的元素 */
#webgl {
    width: 300px;
    height: 300px;
}
```

在 `ts` 中使用 `querySelector` 获取元素并获取 `WebGL2` 上下文：

```TypeScript
const canvas = document.querySelector("#webgl");
const gl = canvas.getContext("webgl2")!;
```

设置画布的像素宽高：

```TypeScript
canvas.width = 300 * devicePixelRatio;
canvas.height = 300 * devicePixelRatio;
```

# 6.7.2 着色器

着色器是一个复杂庞大的概念，我们没办法一次性讲完，我们会在之后的课程中一步步讲解。本节课先来讲解画出三角形所必须的语法与接口。

`WebGL2` 着色器使用 `OpenGL ES 3.0` 标准，使用 `GLSL` 着色器语言。我们不再讲解旧版着色器的内容，直接讲解 `ES 3.0` 着色器。

在 `vscode` 中，我们可以通过 `es6-string-html` 插件来让模板字符串有代码高亮功能，因此我们一般会在着色器代码之前添加一个 `/* glsl */` 的内联注释。

## 声明着色器版本

为了让 `WebGL2` 知道你使用的是 `ES 3.0` 标准，需要在第一行加上 `#version 300 es`，注意是第一行，不能是第二行，也不能是第一行空一格空格开始写。正确与错误示例如下：

```TypeScript
// 正确示例
const source = /* glsl */ `#version 300 es
// 着色器代码
`;

// 错误示例-1 不在第一行
const source = /* glsl */ `
#version 300 es
`;

// 错误示例-2 有空格
const source = /* glsl */ ` #version 300 es
`;

// 错误示例-3 有空格
const source = /* glsl */ `# version 300 es
`;

// 错误示例-4 有分号
const source = /* glsl */ `#versoin 300 es;
`;
```

## 定义数值精度

接下来我们需要定义浮点数的数值精度，它分为 `lowp` `mediump` `highp` 三个精度，分别对应低精度、中精度、高精度，具体区别如下：

| 精度 | 浮点数范围 | 浮点数绝对精度 | 浮点数相对精度 |
|-|-|-|-|
| `lowp` | $(-2,2)$ | $2^{-8}$ | $2^{-8}$ |
| `mediump` | $(-2^{14},2^{14})$ | $2^{-14}$ | $2^{-10}$ |
| `highp` | $(-2^{62},2^{62})$ | $2^{-62}$ | $2^{-16}$ |

一般我们会使用 `mediump` 或 `highp`。

定义精度时使用固定语法 `precision highp float;` 分号不能少，示例如下：

```OpenGL Shading Language
#version 300 es
precision highp float;
```

## 基本语法

`GLSL` 语法与 `C` 语言类似。需要注意的点如下：

1. 每一条语句后面都必须添加分号。
2. 变量等必须声明类型。

### 整数与浮点数

定义整数直接写数字，例如 `1` `2`。

定义浮点数必须包含小数点，例如 `1.0` `2.` `.3`，`2.` 就是 `2.0`，`.3` 就是 `0.3`。一般我们不会使用后两种写法，只会使用第一种写法，因为它更直观。

浮点数使用 `float` 定义，整数使用 `int` 定义。示例在后面给出。

注意，在着色器中，我们很少使用整数，多数情况下使用浮点数，这是因为显卡计算浮点数更快。除了循环、枚举等场景，一般都使用浮点数作为变量。

### 定义变量

定义变量时使用 `类型+变量名` 的格式：

```OpenGL Shading Language
float color; // 仅声明
float color = 1.0; // 声明并赋值初始值
int i = 0; // 定义整数
```

### 布尔值

布尔值使用 `bool` 定义：

```OpenGL Shading Language
bool isXxx = false;
bool greater = 1.0 > 0.5;
```

### 定义函数

定义函数使用 `返回值类型+函数名+参数` 的形式。例如：

```OpenGL Shading Language
void func1(); // 声明一个没有参数没有返回值的函数
void func2(float num, int i); // 有两个参数，没有返回值的函数
float func3(); // 有返回值，没有参数的函数
int func4(float num, int i); // 有返回值，有两个参数的函数
```

### 函数实现

直接在函数声明后面跟上花括号即可实现函数定义：

```OpenGL Shading Language
float func1() {
    return 1.0; // 返回浮点数
}

float func2(float num1, float num2) {
    return num1 * num2; // 返回两个参数的乘积
}
```

### 函数调用

与 `js` 类似，使用圆括号调用：

```OpenGL Shading Language
float num = func2(1.0, 2.0);
```

函数必须先声明再调用，例如下面这样会引起报错：

```OpenGL Shading Language
float num = func2(1.0, 2.0);

float func2(float num1, float num2) {
    return num1 * num2; // 返回两个参数的乘积
}
```

我们可以在前面提前写一个声明而不实现：

```OpenGL Shading Language
float func2(float num1, float num2); // 提前写一个声明

float num = func2(1.0, 2.0);

float func2(float num1, float num2) {
    return num1 * num2; // 返回两个参数的乘积
}
```

或者干脆把实现提到前面：

```OpenGL Shading Language
float func2(float num1, float num2) {
    return num1 * num2; // 返回两个参数的乘积
}

float num = func2(1.0, 2.0);
```

### 强制类型转换

浮点数与整数相乘结果会是浮点数，如果我们需要获取整数，就需要强制类型转换。强制类型转换使用 `(类型)值` 的形式，例如：

```OpenGL Shading Language
int num = (int)(3.0 * 2.0); // 强制转换结果为整数，这会向下取整，可能需要注意浮点误差
float n = (float)num; // 强制转换为浮点数
```

### 输入变量

片段着色器与顶点着色器都有输入变量，直接使用 `in` 关键字定义即可，注意不能赋初始值，因为它是由外部传入的，并非着色器代码本身的变量。

定义顶点着色器的输入变量时，一般使用 `a_变量名` 的格式，定义片段着色器的输入变量时，一般使用 `v_变量名` 的格式。原因在之后可能会讲到。

示例如下，注意不要忘记分号：

```OpenGL Shading Language
in float a_vertexFloat; // 顶点着色器输入变量
in float v_fragFloat; // 片段着色器的输入变量
```

### 输出变量

片段着色器与顶点着色器都有输出变量，使用 `out` 关键字定义，可以赋初始值，因为它是着色器内部定义的，输出到外部。

定义顶点着色器的输出变量时，一般使用 `v_变量名` 的格式，定义片段着色器的输出变量时，没有命名格式要求，但一般以 `out` 开头。

示例如下：

```OpenGL Shading Language
out float v_vertexOut; // 顶点着色器输出变量
out vec4 outColor; // 片段着色器输出变量
```

### 向量数据类型

向量数据类型包括 `vec2` `vec3` `vec4`，它们分别描述了二维、三维、四维向量，分别包含两个、三个、四个浮点数。示例如下：

```OpenGL Shading Language
vec2 v1 = vec2(1.0, 0.2); // 二维向量
vec3 v2 = vec3(1.0, 0.3, 0.8); // 三维向量
vec4 v3 = vec4(1.0, 2.0, 3.3, 1.1); // 四维向量
```

还可以使用向量声明向量，比如在三维向量的基础上加一位变成四维向量：

```OpenGL Shading Language
vec3 v1 = vec3(1.0, 2.2, 0.5);
vec4 v2 = vec4(v1, 1.0); // 在后面添加一个 1.0
vec4 v3 = vec4(1.0. v1); // 在前面添加一个 1.0
```

这类似于 `js` 中的扩散语法。但是注意最大只有四维向量，没有五维或更高的向量。

我们可以通过 `.rgba` 或 `.xyzw` 获取向量的第一、二、三、四个数值。

例如获取 `vec4` 的第三项，就有两种写法：

```OpenGL Shading Language
vec4 v = vec4(1.0, 2.0, 3.3, 1.1); // 四维向量
float f1 = v.b; // 获取第三项
float f2 = v.z; // 获取第三项
```

`.rgba` 和 `.xyzw` 可以自由组合，顺序也可以颠倒，程序会根据其顺序依次取出并组成一个新的向量。但是两个获取方式是不能混用的。示例如下：

```OpenGL Shading Language
vec4 v = vec4(1.0, 2.0, 3.0, 4.0);
vec2 v1 = v.ra; // 获取第一项和最后一项，结果为 vec2(1.0, 4.0)
vec3 v2 = v.zyx; // 倒序获取前三项，结果为 vec3(3.0, 2.0, 1.0)
```

### 顶点输出

这里的顶点输出是指顶点着色器输出的顶点坐标，并非 `out` 变量，注意区分。

我们计算出顶点位置后，需要让 `WebGL2` 知道位置是什么，此时我们需要将运算结果赋值给 `gl_Position` 内置变量。例如：

```OpenGL Shading Language
vec4 pos = vec4(0.0, 1.0, 0.5, 1.0);
gl_Position = pos; // 将顶点输出赋值给 gl_Position
```

### 片段输出

这里的片段输出是指片段着色器输出的颜色。

我们直接将颜色赋值给使用 `out` 定义的变量即可：

```OpenGL Shading Language
out vec4 outColor;
outColor = vec4(0.0, 0.0, 0.0, 1.0); // 赋值给 out 变量
```

### 主程序

顶点着色器和片段着色器都有一个主程序，它是 `main` 函数，显卡会从这里开始执行着色器，他就是着色器的入口。因此 `main` 函数是必不可少的。示例如下：

```OpenGL Shading Language
void main() {
    gl_Position = pos; // 顶点着色器输出顶点
}
```

### 其他语法

其他语法包括基本数学运算、逻辑运算、循环、条件判断等基本与 `js` 语法一致，这里不再细讲，后面直接给出一个示例。

需要注意的是 `glsl` 的数学运算符很少，只包含加减乘除等，不包含取余、位运算等运算符。

```OpenGL Shading Language
float num = (1.0 + 2.0) * 3.0 / 4.0;
bool logic = (false && true) || false;
float n = 1.0 > 2.0 ? 1.0 : 2.0;

if (logic && 2.0 > 1.0) {
}

while (logic) {
    break;
}

for (int i = 0; i < 10; i++) {
}
```

# 6.7.3 编写着色器

讲解完着色器的语法后，我们就可以开始编写着色器了。

## 顶点着色器

首先来看顶点着色器。

顶点着色器的目标是确定顶点。我们画三角形时会传入三角形的顶点，因此直接将传入的顶点作为输出即可。

我们需要先定义一个输入变量 `a_position`，它就是三角形的顶点坐标，然后直接赋值给 `gl_Position`。代码如下：

```OpenGL Shading Language
#version 300 es
precision highp float;

in vec4 a_position;

void main() {
    gl_Position = a_position;
}
```

## 片段着色器

我们需要将三角形填充成白色，因此直接将输出颜色设为白色即可：

```OpenGL Shading Language
#version 300 es
precision highp float;

out vec4 outColor;

void main() {
    outColor = vec4(1.0, 1.0, 1.0, 1.0); // 分别代表 rgba
}
```

# 6.7.4 编译着色器与链接程序

我们编写完了着色器，接下来我们就需要编译并链接程序了。

## 编译着色器

编译某个着色器使用如下代码：

```TypeScript
const shader = gl.createShader(gl.VERTEX_SHADER);
gl.shaderSource(shader, vs);
gl.compileShader(shader);
```

有时候着色器代码有问题，会编译失败，这时候 `WebGL2` 并不会报错，而是会继续往下执行。我们需要判断是否编译完成，使用这段代码：

```TypeScript
if (!gl.getShaderParameter(shader, gl.COMPILE_STATUS)) {
    const info = gl.getShaderInfoLog(shader);
    throw new Error(`无法编译着色器。\n\n${info}`);
}
```

我们有顶点着色器和片段着色器两个着色器，因此需要写两遍，为了不这么麻烦，我们可以把上述过程封装成一个函数：

```TypeScript
/**
 * 编译着色器
 * @param type 着色器类型
 * @param source 着色器代码
 */
function compileShader(type: GLenum, source: string): WebGLShader {
  const shader = gl.createShader(type);
  gl.shaderSource(shader, source);
  gl.compileShader(shader);
  
  // 如果编译失败
  if (!gl.getShaderParameter(shader, gl.COMPILE_STATUS)) {
    const info = gl.getShaderInfoLog(shader);
    throw new Error(`无法编译着色器。\n\n${info}`);
  }
  
  return shader;
}
```

于是我们直接调用就可以了：

```TypeScript
const vsShader = compileShader(gl.VERTEX_SHADER, vs);
const fsShader = compileShader(gl.FRAGMENT_SHADER, fs);
```

## 链接程序

根据上一节课讲过的过程创建并链接程序即可：

```TypeScript
const program = gl.createProgram();
gl.attachShader(program, vsShader);
gl.attachShader(program, fsShader);
gl.linkProgram(program);
```

链接程序后，我们还需要判断程序是否链接成功，就像判断着色器是否编译成功一样，使用如下代码：

```TypeScript
if (!gl.getProgramParameter(program, gl.LINK_STATUS)) {
  const info = gl.getProgramInfoLog(program);
  throw new Error(`无法编译 WebGL 程序。\n\n${info}`);
}
```

# 6.7.5 顶点数组

我们需要使用顶点数组指定三角形画到哪。

## 定义顶点数组

我们以 $(-0.5,-0.5)$ $(0.5,-0.5)$ $(0,0.5)$ 三个点组成三角形。定义顶点数组：

```TypeScript
const vertex = new Float32Array([-0.5, -0.5, 0.5, -0.5, 0, 0.5]);
```

绑定并赋值到缓冲区：

```TypeScript
const buffer = gl.createBuffer();
gl.bindBuffer(gl.ARRAY_BUFFER, buffer);
gl.bufferData(gl.ARRAY_BUFFER, vertex, gl.STATIC_DRAW);
```

## 获取输入变量位置

我们需要将上述顶点数组传递给着色器的 `a_position` 输入变量。我们需要先通过 `gl.getAttribLocation` 方法来获取输入变量的位置：

```TypeScript
function getAttribLocation(program: WebGLProgram, attrib: string): number;
```

第一个参数代表要获取哪个程序的输入变量，第二个参数代表输入变量的名称，会返回一个数字，代表输入变量的位置。示例如下：

```TypeScript
const location = gl.getAttribLocation(program, 'a_position');
```

## 传递顶点数组

接下来我们需要使用 `gl.vertexAttribPointer` 来传递顶点数组。它的类型声明如下：

```TypeScript
function vertexAttribPointer(
    index: number,
    size: number,
    type: GLenum,
    normalized: boolean,
    stride: number,
    offset: number
): void;
```

它的功能是将当前绑定在 `gl.ARRAY_BUFFER` 缓冲区的内容传递给指定位置的顶点输入变量。我们刚刚将顶点数组绑定至了 `gl.ARRAY_BUFFER` 缓冲区，那么我们需要将刚刚获取的输入变量位置传入，这样顶点数组就会传递给顶点变量了。

它的每个参数解释如下：

- `index`：顶点输入变量的位置，即刚刚用 `getAttribLocation` 获取到的值。
- `size`：每个数据的大小，填 1 代表浮点数，填 2 代表二维向量，以此类推。
- `type`：数据类型，可以填 `gl.BYTE` `gl.SHORT` `gl.FLOAT` 等，分别代表八位整数、十六位整数、三十二位浮点数等。
- `normalized`：是否对数据归一化，对整数类型有效，浮点数无效。对于有符号整数，会归一化至 `[-1,1]` 的区间，对于无符号整数，会归一化至 `[0,1]` 的区间。
- `stride`：连续的两个顶点属性的间距，以字节为单位。以浮点数来说，如果此值是 16，`size` 是 3，那么会依次读取 `0,1,2,4,5,6,8,9,10` 索引的数据。此参数最大值是 255。如果填 0，那么相当于 `size*byte`，即填 0 的时候每个数据之间是挨着的。
- `offset`：数据从哪个字节开始读取，注意是字节偏移量，而非索引偏移量。

图示如下：

那么在我们现在的场景下，应该如下填写参数：

```TypeScript
gl.vertexAttribPointer(
    location, // 传入刚刚获取的输入变量位置
    2, // 每个点两个坐标，因此传入 2
    gl.FLOAT, // 每个坐标都是浮点数
    false, // 浮点数不需要归一化
    0, // 顶点属性间连续，因此填 0
    0 // 不需要偏移
);
```

这里也解释了上一节课中的疑问，`WebGL2` 如何知道顶点数组是几个一组的呢？答案是在传入顶点数组的时候指定，而不是定义顶点数组的时候指定，这样的话顶点数组就可以复用了。

## 启用顶点数组

最后，我们需要使用 `gl.enableVertexAttribArray` 来启用刚刚传入的顶点数组：

```TypeScript
function enableVertexAttribArray(index: number): void;
```

参数就是输入变量的位置，我们直接传入即可：

```TypeScript
gl.enableVertexAttribArray(location);
```

我们需要使用 `gl.useProgram` 告诉 `WebGL2` 要使用什么着色器程序渲染。其类型声明如下：

```TypeScript
function useProgram(program: WebGLProgram): void;
```

我们刚刚创建并设定完毕了需要使用的程序，直接传入即可：

```TypeScript
gl.useProgram(program);
```

# 6.7.7 执行渲染

我们总算是来到了最后一步，终于可以开始渲染内容了！

## 设定视口

我们首先按照上一节课的内容设定视口：

```TypeScript
gl.viewport(0, 0, canvas.width, canvas.height);
```

## 清空画布

接下来按照上一节课的内容清空画布：

```TypeScript
gl.clearColor(0, 0, 0, 1);
gl.clearDepth(1);
gl.clear(gl.COLOR_BUFFER_BIT | gl.DEPTH_BUFFER_BIT);
```

## 执行渲染

最后，我们调用 `gl.drawArrays`，它的类型声明如下：

```TypeScript
function drawArrays(mode: GLenum, first: number, count: number): void;
```

其中第一个参数表示线的连接方式，就是上一节课中讲到的 `gl.TRIANGLES` `gl.TRIANGLE_STRIP` `gl.TRIANGLE_FANS`。

第二个参数是指从哪个点开始渲染，第三个参数代表要渲染多少个点。

我们的场景中只有一个三角形，因此三种连接方式都没有区别，我们选用 `gl.TRIANGLES`。三个顶点需要全部花完，因此 `first` 和 `count` 分别传入 0 和 3。

最后代码如下：

```TypeScript
gl.drawArrays(gl.TRIANGLES, 0, 3);
```

# 6.7.8 渲染流程解释

## 执行顶点着色器

当我们执行了 `drawArrays` 后，`WebGL2` 会检查所有启用的顶点数组，并将它们按照指定的方式组成浮点数或向量，逐个传入顶点着色器的输入变量，并执行顶点着色器的主程序。

对于我们的顶点数组 `[-0.5, -0.5, 0.5, -0.5, 0, 0.5]`，会被分割为三个 `vec2`，即 `vec2(-0.5, -0.5)` `vec2(0.5, -0.5)` `vec2(0, 0.5)`，于是着色器中的输入变量 `a_position` 就会依次被赋值为它，并执行主程序。我们将 `a_position` 直接赋值给了 `gl_Position`，因此最后三角形的顶点也就是这三个坐标。

我们定义的 `a_position` 是 `vec4`，但是传入了 `vec2`，此时 `a_position` 将会是 `vec4(vec2, 0, 1)`，即 `z w` 坐标分别被填充为 0 和 1。

## 光栅化

当确定了顶点之后，`WebGL2` 会遍历顶点构成区域内的所有像素。由于顶点等坐标都是浮点数，需要对应到屏幕像素，因此需要分割成一个个的像素，这一行为被称为光栅化。

## 执行片段着色器

最后确定了所有要渲染的像素后，会对每个像素执行片段着色器，将其输出的颜色推送到颜色缓冲区，并在屏幕上显示。

# 6.7.9 完整代码

```TypeScript
// 创建画布
const canvas = document.querySelector("#webgl");
const gl = canvas.getContext("webgl2")!;

//设置画布宽高
canvas.width = 300 * devicePixelRatio;
canvas.height = 300 * devicePixelRatio;

// 顶点着色器
const vs = /* glsl */ `#version 300 es
precision highp float;

in vec4 a_position;

void main() {
  gl_Position = a_position;
}
`;

// 片段着色器
const fs = /*glsl */ `#version 300 es
precision highp float;

out vec4 outColor;

void main() {
  outColor = vec4(1.0, 1.0, 1.0, 1.0);
}
`;

// 编译着色器
const vsShader = compileShader(gl.VERTEX_SHADER, vs)
const fsShader = compileShader(gl.FRAGMENT_SHADER, fs);

// 创建程序并编译链接
const program = gl.createProgram();
gl.attachShader(program, vsShader);
gl.attachShader(program, fsShader);
gl.linkProgram(program);

// 如果程序链接失败
if (!gl.getProgramParameter(program, gl.LINK_STATUS)) {
  const info = gl.getProgramInfoLog(program);
  throw new Error(`无法编译 WebGL 程序。\n\n${info}`);
}

// 定义顶点数组，并赋值给缓冲区
const vertex = new Float32Array([-0.5, -0.5, 0.5, -0.5, 0, 0.5]);
const buffer = gl.createBuffer();
gl.bindBuffer(gl.ARRAY_BUFFER, buffer);
gl.bufferData(gl.ARRAY_BUFFER, vertex, gl.STATIC_DRAW);

// 获取顶点属性地址
const attrib = gl.getAttribLocation(program, "a_position");
// 指定顶点数组并启用
gl.vertexAttribPointer(attrib, 2, gl.FLOAT, false, 0, 0);
gl.enableVertexAttribArray(attrib);

// 使用着色器程序
gl.useProgram(program);

// 设置视口并清空画布
gl.viewport(0, 0, canvas.width, canvas.height);
gl.clearColor(0, 0, 0, 1);
gl.clearDepth(1);
gl.clear(gl.COLOR_BUFFER_BIT | gl.DEPTH_BUFFER_BIT);

// 执行渲染
gl.drawArrays(gl.TRIANGLES, 0, 3);

/**
 * 编译着色器
 * @param type 着色器类型
 * @param source 着色器代码
 */
function compileShader(type: GLenum, source: string): WebGLShader {
  const shader = gl.createShader(type);
  gl.shaderSource(shader, source);
  gl.compileShader(shader);
  
  // 如果编译失败
  if (!gl.getShaderParameter(shader, gl.COMPILE_STATUS)) {
    const info = gl.getShaderInfoLog(shader);
    throw new Error(`无法编译着色器。\n\n${info}`);
  }
  
  return shader;
}
```
