# 6.10.1 `gl-matrix` 库的基本使用

进行三维渲染时我们需要 MVP 变换，我们一般使用 `gl-matrix` 库，人类塔中包含了这个库，如果你通过人类塔学习，可以直接使用。如果想要自己尝试，可以自己通过 `pnpm create vite` 创建一个 `vite` 项目，并 `pnpm add gl-matrix` 安装后尝试。

或者使用 `CodePen` 网站，可以直接引入，上面的代码链接就使用了 `CodePen`。

`gl-matrix` 包含二维、三维变换矩阵，我们着重讲解三维变换矩阵。

## 创建矩阵

首先需要使用 `mat4.create` 创建矩阵：

```TypeScript
function create(): mat4;
```

它会创建一个单位矩阵，返回值 `mat4` 是一个 `Float32Array`，官方文档全部使用了 `mat4` 作为类型，这里我们也使用它。我们画三维物体需要四个矩阵，一个用于存储最终计算结果，另外三个分别是 mvp 矩阵。示例如下：

```TypeScript
import { mat4 } from 'gl-matrix';

const trans = mat4.create();
const model = mat4.create();
const view = mat4.create();
const proj = mat4.create();
```

## 操作矩阵的基本模式

`gl-matrix` 操作矩阵时，都会要求传入一个输出目标，运算结果将会存储到传入的矩阵中，与传统的接口设计并不相同。举例来说，将一个矩阵设为单位矩阵的方法如下：

```TypeScript
function identity(out: mat4): mat4;
```

这里的 `out` 就是要设为单位矩阵的矩阵，返回值就是传入的 `out`。例如我们需要每帧将 `trans` 设为单位矩阵，可以这么写：

```TypeScript
mat4.identity(trans);
```

## 矩阵相乘

使用 `multiply` 做乘法：

```TypeScript
function multiply(out: mat4, a: mat4, b: mat4): mat4;
```

这里的 `out` 是运算结果，`a` 是乘号左侧的矩阵（左操作数），`b` 是右操作数。

例如：

```TypeScript
// 先模型变换，再视角变换，最后投影变换
mat4.multiply(trans, trans, proj);
mat4.multiply(trans, trans, view);
mat4.multiply(trans, trans, model);
```

## 模型变换

### 基础用法

`gl-matrix` 有 `translate` `rotate` `scale` 方法用来执行模型变换，它们的类型声明如下：

```TypeScript
function translate(out: mat4, a: mat4, v: vec3): mat4;
function rotate(out: mat4, a: mat4, rad: number, axis: vec3): mat4;
function rotateX(out: mat4, a: mat4, rad: number): mat4;
function rotateY(out: mat4, a: mat4, rad: number): mat4;
function rotateZ(out: mat4, a: mat4, rad: number): mat4;
function scale(out: mat4, a: mat4, v: vec3): mat4;
```

这里的 `out` 都代表输出矩阵，`a` 代表输入矩阵，即要进行操作的矩阵。

- 平移变换 `translate`：`v` 代表在 `x y z` 三个方向上的平移量。
- 旋转变换 `rotate` `rotateX` `rotateY` `rotateZ`：第一个方法代表沿某个轴旋转 `rad` 弧度，其中旋转轴用一个三维向量描述，例如沿 `[1, 1, 1]` 轴旋转。后面三个方法代表沿 `x y z` 轴旋转 `rad` 弧度。
- 缩放变换 `scale`：`v` 代表在 `x y z` 三个方向上的缩放量。

例如，我们想先缩放，再旋转，再平移，可以这么写：

```TypeScript
mat4.translate(model, model, [1, 1, 1]); // 三个方向各平移一个单位
mat4.rotate(model, model, Math.PI / 2, [1, 1, 1]); // 沿斜 45 度方向旋转 90 度
mat4.scale(model, model, [1, 2, 1]); // 在 y 方向缩放为 2 倍
```

### `from` 系列方法

除了这些方法，如果我们不需要非常复杂的组合变换，可以通过一系列 `from` 方法来实现，它的运算速度要比上述方法快得多。

通过平移、旋转、缩放创建使用这些接口：

```TypeScript
function fromTranslation(out: mat4, v: vec3): mat4;
function fromRotation(out: mat4, rad: number, axis: vec3): mat4;
function fromXRotation(out: mat4, rad: number): mat4;
function fromYRotation(out: mat4, rad: number): mat4;
function fromZRotation(out: mat4, rad: number): mat4;
function fromScaling(out: mat4, v: vec3): mat4;
```

这些接口与前面讲的那些接口类似，只不过会重置矩阵并只进行一次变换操作。以 `fromTranslation` 为例，它与如下代码一致：

```TypeScript
mat4.identity(model);
mat4.translate(model, v);
```

但是要更快，因此更推荐用这种方法。示例如下：

```TypeScript
mat4.fromTranslation(model, [1, 1, 1]); // 将矩阵设为平移矩阵
mat4.fromScaling(model, [1, 2, 1]); // 将矩阵设为缩放矩阵，前一步平移将不会生效
```

## 四元数

我们可以用一个四元组描述旋转 `[qx, qy, qz, qw]`，其中 `qx, qy, qz` 表示旋转轴，`qw` 是旋转角度一半的余弦值，即 $\cos\frac{\theta}{2}$。

我们可以用 `quat.create` 创建：

```TypeScript
function create(): quat;
```

旋转使用的方法与 `mat4` 类似，但没有 `rotate` 方法：

```TypeScript
function rotateX(out: quat, a: quat, rad: number): quat;
function rotateY(out: quat, a: quat, rad: number): quat;
function rotateZ(out: quat, a: quat, rad: number): quat;
```

我们可以通过一个四元数直接生成 `mat4` 矩阵：

```TypeScript
function fromQuat(out: mat4, q: quat): mat4;
```

例如：

```TypeScript
import { mat4, quat } from 'gl-matrix';
const model = mat4.create();
const q = quat.create();
quat.rotateX(q, q, Math.PI / 2);
mat4.fromQuat(model, q);
```

## 复杂模型变换

除了使用基本的 `from` 方法，还有一些用于复杂变换的 `from` 系列方法。这些方法仅说明一下它们相当于什么代码，不再提供例子。

第一个方法：

```TypeScript
function fromRotationTranslation(out: mat4, q: quat, v: vec3): mat4;
```

它以指定四元数和平移生成矩阵，先旋转再平移，相当于：

```TypeScript
mat4.identity(model);
mat4.translate(model, model, v);
const quatMat = mat4.create();
mat4.fromQuat(quatMat, quat); 
mat4.multiply(model, model, quatMat);
```

但是这个方法将这些方法整合成了一步，速度要快很多，而且写起来也更方便了。

第二个方法：

```TypeScript
function fromRotationTranslationScale(out: mat4, q: quat, v: vec3, s: vec3): mat4;
```

先缩放，再旋转，最后平移，相当于：

```TypeScript
mat4.identity(model);
mat4.translate(model, model, vec);
const quatMat = mat4.create();
mat4.fromQuat(quatMat, quat);
mat4.multiply(model, model, quatMat);
mat4.scale(model, model, scale)
```

第三个方法：

```TypeScript
function fromRotationTranslationScaleOrigin(out: mat4, q: quat, v: vec3, s: vec3, o: vec3): mat4;
```

先缩放，再旋转，最后平移，不过缩放与旋转不再相对于原点，而是相对于 `o` 参数指定的点。相当于：

```TypeScript
mat4.identity(model);
mat4.translate(model, model, vec);
mat4.translate(model, model, origin);
const quatMat = mat4.create();
mat4.fromQuat(quatMat, quat);
mat4.multiply(model, model, quatMat);
mat4.scale(model, model, scale);
mat4.translate(model, model, negativeOrigin);
```

## 视角变换

视角变换使用 `mat4.lookAt` 方法：

```TypeScript
function lookAt(out: mat4, eye: vec3, center: vec3, up: vec3): mat4;
```

这里的 `eye` 表示摄像机的位置，`center` 表示看向的点，`up` 表示摄像机上朝向。

例如我们想要正面看向屏幕内，`up` 方向朝上，可以这么写：

```TypeScript
mat4.lookAt(view, [0, 0, 1], [0, 0, 0], [0, 1, 0]);
```

## 投影变换

投影变换使用 `mat4.ortho` 和 `mat4.perspective`，前者是正交投影，后者是透视投影：

```TypeScript
function ortho(out: mat4, left: number, right: number, bottom: number, top: number, near: number, far: number): mat4;
function perspective(out: mat4, fovy: number, aspect: number, near: number, far: number): mat4;
```

这些参数在 5.4 的课程中都已经讲解到了，这里不再讲解。示例如下：

```TypeScript
mat4.ortho(proj, -1, 1, -1, 1, 0.1, 100);
mat4.perspective(proj, Math.PI / 4, 1, 0.1, 100);
```

# 6.10.2 着色器

我们需要画出一个旋转的正方体，而且六个面有不同的颜色。

## 矩阵类型

在编写着色器之前，我们需要了解一下 `GLSL` 的矩阵类型，它用来描述一个矩阵。矩阵类型包括：`mat2` `mat2x3` `mat2x4` `mat3` `mat3x4` `mat4`，分别代表 `2*2` `2*3` `2*4` `3*3` `3*4` `4*4` 大小的矩阵。前一个数字代表列数，后一个数字代表行数，例如 `mat2x3` 表示一个二列三行的矩阵。例如我们想创建一个 `2*2` 矩阵，就像上节课那样，可以这么写：

```OpenGL Shading Language
mat2 mat = mat2(
    1, 0,
    0, 1
);
```

这里换行是为了代码更清晰，实际上不换行也行，但是代码会变得难以阅读：

```OpenGL Shading Language
mat2 mat = mat2(1, 0, 0, 1);
```

当然，矩阵还可以作为 `uniform` 变量：

```OpenGL Shading Language
uniform mat4 u_transform;
```

## 顶点着色器

我们需要给顶点着色器添加变换矩阵，同时保留顶点位置与颜色的顶点输入，因此着色器内容为：

```OpenGL Shading Language
#version 300 es
precision highp float;

// 位置与颜色信息
in vec4 a_position;
in vec4 a_color;

// 变换矩阵
uniform mat4 u_transform;

out vec4 v_color;

void main() {
  v_color = a_color;
  gl_Position = u_transform * a_position;
}
```

## 片段着色器

片段着色器维持不变：

```OpenGL Shading Language
#version 300 es
precision highp float;

in vec4 v_color;
out vec4 outColor;

void main() {
  outColor = v_color;
}
```

# 6.10.3 顶点数组

## 定义正方体

我们需要定义正方体顶点数组。为了更加清晰，我们可以把顶点坐标与颜色写在一起，然后使用 `stride` 参数控制顶点数组的读取。

为了避免插值问题，让每个面的颜色是单一的，我们需要使用 `gl.TRIANGLES` 连接方式，因为其他的连接方式都与前面的点有关系，必然会产生插值。

除此之外还要注意剔除问题，逆向三角形会被剔除（顺时针三角形），这需要一定的空间想象力。一个面旋转到正面之后应该是正向三角形（逆时针三角形），因此在我们的视角下，背面的三角形应该是逆向的，只有这样旋转到正面之后才会变成顺向。其他面也是类似。

正方体一个面有四个顶点，需要两个三角形。四个顶点编号为 `1 2 3 4`，假设在正面时它们逆时针旋转，那么三角形的顶点依次是 `1 2 3 2 3 4`，即按顺序编写并重复中间两个顶点。

因此顶点数组编写如下，前三项代表坐标，后四项代表颜色：

```TypeScript
const array = new Float32Array([
  0.5, 0.5, 0.5,    1, 0, 0, 1,
  -0.5, 0.5, 0.5,   1, 0, 0, 1,
  0.5, -0.5, 0.5,   1, 0, 0, 1, // 前面右上角三角形
  0.5, -0.5, 0.5,   1, 0, 0, 1,
  -0.5, 0.5, 0.5,   1, 0, 0, 1,
  -0.5, -0.5, 0.5,  1, 0, 0, 1, // 前面左下角三角形
  
  0.5, 0.5, 0.5,    0, 1, 0, 1,
  0.5, 0.5, -0.5,   0, 1, 0, 1,
  -0.5, 0.5, -0.5,  0, 1, 0, 1, // 上面右后方三角形
  -0.5, 0.5, -0.5,  0, 1, 0, 1,
  -0.5, 0.5, 0.5,   0, 1, 0, 1,
  0.5, 0.5, 0.5,    0, 1, 0, 1, // 上面左前方三角形
  
  -0.5, 0.5, 0.5,   0, 0, 1, 1,
  -0.5, 0.5, -0.5,  0, 0, 1, 1,
  -0.5, -0.5, 0.5,  0, 0, 1, 1, // 左面上前方三角形
  -0.5, -0.5, 0.5,  0, 0, 1, 1,
  -0.5, 0.5, -0.5,  0, 0, 1, 1,
  -0.5, -0.5, -0.5, 0, 0, 1, 1, // 左面下后方三角形
  
  0.5, 0.5, 0.5,    1, 1, 0, 1,
  0.5, -0.5, 0.5,   1, 1, 0, 1,
  0.5, 0.5, -0.5,   1, 1, 0, 1, // 右面上前方三角形
  0.5, 0.5, -0.5,   1, 1, 0, 1,
  0.5, -0.5, 0.5,   1, 1, 0, 1,
  0.5, -0.5, -0.5,  1, 1, 0, 1, // 右面下后方三角形
  
  0.5, -0.5, -0.5,  1, 0, 1, 1,
  0.5, -0.5, 0.5,   1, 0, 1, 1,
  -0.5, -0.5, -0.5, 1, 0, 1, 1, // 下面右后方三角形
  -0.5, -0.5, -0.5, 1, 0, 1, 1,
  0.5, -0.5, 0.5,   1, 0, 1, 1,
  -0.5, -0.5, 0.5,  1, 0, 1, 1, // 下面左前方三角形
  
  0.5, 0.5, -0.5,   0, 1, 1, 1,
  0.5, -0.5, -0.5,  0, 1, 1, 1,
  -0.5, 0.5, -0.5,  0, 1, 1, 1, // 后面右上方三角形
  -0.5, 0.5, -0.5,  0, 1, 1, 1,
  0.5, -0.5, -0.5,  0, 1, 1, 1,
  -0.5, -0.5, -0.5, 0, 1, 1, 1, // 后面左下方三角形
]);
```

## 传递顶点数组

这次我们只需要绑定一个缓冲区，然后使用 `stride` 和 `offset` 参数调整顶点数组的读取方式。

数据类型是 `Float32`，占用四字节，每组数据包含七个数据，因此 `stride` 应该填 `7*4`。

颜色从第四项开始读取，因此偏移量 `offset` 应该填写 `3*4`。

因此完整代码如下：

```TypeScript
// 顶点赋值给缓冲区
const buffer = gl.createBuffer();
gl.bindBuffer(gl.ARRAY_BUFFER, buffer);
gl.bufferData(gl.ARRAY_BUFFER, array, gl.STATIC_DRAW);

// 传递并启用顶点数组
const position = gl.getAttribLocation(program, 'a_position');
gl.vertexAttribPointer(position, 3, gl.FLOAT, false, 7 * 4, 0);
gl.enableVertexAttribArray(position);

// 传递并启用颜色数组
const color = gl.getAttribLocation(program, 'a_color');
gl.vertexAttribPointer(color, 4, gl.FLOAT, false, 7 * 4, 3 * 4);
gl.enableVertexAttribArray(color);

```

使用这种方式，我们只需要创建一个类型化数组，更加直观，而且只需要绑定一个缓冲区，运行速度也会提升。

# 6.10.4 变换矩阵

## 视角变换与投影变换

我们需要先创建四个矩阵分别存储 model view projection 变换以及运算结果：

```TypeScript
// 创建变换矩阵
const trans = mat4.create();
const model = mat4.create();
const view = mat4.create();
const proj = mat4.create();
```

视角变换和投影变换不会变化，因此直接写，摄像机在 `[0, 3, 4]` 的位置看向原点，相当于向前下方看；视角选用 45°，这个视角下的透视关系与人眼相似（等效焦距约 50mm）：

```TypeScript
mat4.lookAt(view, [0, 3, 4], [0, 0, 0], [0, 1, 0]);
mat4.perspective(proj, Math.PI / 4, 1, 0.1, 10);
```

## 模型变换

正方体在旋转，因此我们需要每帧设定它的模型变换。

这里我们不再使用每帧加上角度的方式，因为帧率会影响结果，我们换为使用时间计算角度的方式。我们只需要设定一个常数，让它乘以时间作为旋转角度即可，为了避免数据溢出，我们还需要将角度范围限定在 `[0, 2*pi]` 范围内：

```TypeScript
// 使用 time 计算角度，与帧率不绑定
let angle = time / 500;
if (time > Math.PI * 2) {
    // 确保范围在 [0, 2*pi] 之间
    const n = Math.floor(time / Math.PI / 2);
    angle -= Math.PI * 2 * n;
}
```

然后使用 `fromYRotation` 方法生成矩阵：

```TypeScript
mat4.fromYRotation(model, angle);
```

## 计算变换矩阵

接下来，我们只需要将三个矩阵倒序相乘即可，注意计算前需要先把结果重置为单位矩阵：

```TypeScript
// 重置并计算变换矩阵
mat4.identity(trans);
mat4.multiply(trans, trans, proj);
mat4.multiply(trans, trans, view);
mat4.multiply(trans, trans, model);
```

## 传递变换矩阵

传递变换矩阵不再使用上一节课讲的 `uniform[1234][uif][v]` 方法，它使用 `uniformMatrix[234]x[234]fv` 方法。一个典型的名称是 `uniformMatrix2x3fv`，表示传递一个 `mat2x3`，即一个二列三行的矩阵。而对于 `mat2` `mat3` `mat4`，则不使用 `uniformMatrix2x2fv` 这种命名方式，而是简写成 `uniformMatrix2fv` 这种形式。

这个系列方法的命名方式较为直观简单，不再画图说明。

每种方法的用法都一致，类型声明如下：

```TypeScript
function uniformMatrix[234]x[234]fv(
    location: WebGLUniformLocation,
    transpose: boolean,
    data: Float32Array,
    srcOffset?: number,
    srcLength?: number
): void;
```

每个参数含义如下：

- `location`：`uniform` 变量位置，使用 `getUniformLocation` 获取。
- `transpose`：是否对矩阵转置，`GLSL` 使用列主序矩阵，如果运算时使用了行主序，那么需要转置。我们使用 `gl-matrix` 库，并不需要转置。
- `data`：矩阵内容。
- `srcOffset` `srcLength`：读取时使用的索引偏移量与长度。

我们需要传递一个变换矩阵，因此使用 `uniformMatrix4fv` 方法：

```TypeScript
// uniform 变量地址，不需要每帧执行
const transform = gl.getUniformLocation(program, 'u_transform');
// 每帧执行
gl.uniformMatrix4fv(transform, false, trans);
```

# 6.10.5 执行渲染

我们需要开启面剔除功能：

```TypeScript
gl.enable(gl.CULL_FACE);
gl.cullFace(gl.BACK);
```

你可以通过调整摄像机的位置检查面剔除是否生效，把摄像机位置设到正方体内（例如 `[0, 0.2, 0.2]`），理应不会显示任何内容。

每帧执行渲染，注意绘制点数不再是 3，而是 `array.length / 7`：

```TypeScript
  gl.clearColor(0, 0, 0, 1);
  gl.clearDepth(1);
  gl.clear(gl.COLOR_BUFFER_BIT | gl.DEPTH_BUFFER_BIT);

  // 执行渲染
  gl.drawArrays(gl.TRIANGLES, 0, array.length / 7);
```

/**
 * 编译着色器
 * @param type 着色器类型
 * @param source 着色器代码
 */
function compileShader(type: GLenum, source: string): WebGLShader {
  const shader = gl.createShader(type);
  gl.shaderSource(shader, source);
  gl.compileShader(shader);
  
  // 如果编译失败
  if (!gl.getShaderParameter(shader, gl.COMPILE_STATUS)) {
    const info = gl.getShaderInfoLog(shader);
    throw new Error(`无法编译着色器。\n\n${info}`);
  }
  
  return shader;
}
