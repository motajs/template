本节课对 `function` 函数类型做复习以及补充。

# 5.3.1 函数声明复习

## 函数声明

我们依然先复习一下函数的声明方式。第一种方法是使用 `function` 关键字：

```TypeScript
function myFunc(param1: type, param2: type, ...params: type[]): ReturnType {
    // 这里写函数内容
}
```

这里的 `param1` `param2` `...params` 就是函数参数，`ReturnType` 就是函数的返回值类型。

函数本身也是一个值，可以被变量、常量或对象的属性接收：

```TypeScript
const myFunc = function() {
    // 这里写函数内容
}
```

在使用变量或常量接收时，我们更习惯使用箭头函数：

```TypeScript
const myFunc = () => {
    // 这里写函数内容
};
```

对于箭头函数，只有一个参数时可以省略括号，也可以省略花括号表示直接将表达式返回：

```TypeScript
const myFunc = x => {}; // 只有一个参数时省略括号
const myFunc = () => 1 + 2 + 3; // 省略花括号直接返回表达式
const myFunc = x => x + 5; // 两个简化写法同时使用
```

## 普通函数与箭头函数的区别

箭头函数与使用 `function` 关键字有两个关键区别：

1. 箭头函数本身没有 `this` 指向，它会继承父作用域的 `this` 指向。这在传递回调函数的场景非常有用：

```TypeScript
class MyClass {
    count: number = 0;
    myMethod() {
        this.count = 0;
        [1, 2, 3, 4].forEach(v => {
            // 箭头函数里面直接写 this 就行
            this.count += v;
        });
        [1, 2, 3, 4].forEach(function (v) {
            // 但是 function 关键字声明的就不行，它有自己的 this 指向，在这个场景下会指向 undefined，于是会报错
            this.count += v;
        });
    }
}
```

1. 箭头函数没有 `arguments`，想获取剩余参数只能通过 `...params` 声明参数。

# 5.3.2 声明规范

我们建议在编写函数时使用一定的规范，常见的有这几种规范：

1. 所有函数都使用箭头函数。
2. 在模块顶层的函数使用 `function` 关键字声明函数，其他函数使用箭头函数。
3. 临时函数使用箭头函数，其他函数使用 `function` 关键字声明函数。

在新样板中，我们遵循了第二个规范，也就是说所有在模块顶层的函数都会使用 `function` 声明，包括导出的函数，而其他的函数全部使用箭头函数，包括函数内的函数、回调函数等。

# 5.3.3 返回值泄漏

使用箭头函数时，可能会出现返回值泄漏的情况。例如我们需要一个函数给一个变量赋值：

```TypeScript
let a = 100;
const myFunc = x => a = x;
```

我们调用 `myFunc` 时会给变量 `a` 赋值，这个行为没什么问题。但是我们省略了花括号，所以这个函数会把 `a = x` 的返回值作为函数的返回值，这就引起了返回值泄漏。返回值泄漏大部分情况下没什么问题，但是在一些特定情况可能会造成一定的安全问题，因此建议这种纯副作用函数使用 `void` 关键字把返回值包裹：

```TypeScript
let a = 100;
const myFunc = x => void(a = x);
```

`void` 关键字的作用在前面的课程中已经讲解到，作用是把紧跟着的表达式的返回值变为 `undefined`。这个圆括号并不是一定需要的，`void` 并不是一个函数，而是一个关键字，在优先级正确的前提下可以删除圆括号。

或者干脆直接加上花括号：

```TypeScript
let a = 100;
const myFunc = x => { a = x; };
```

# 5.3.4 函数方法

函数也是一个对象，其有一些方法允许我们实现一些更高级的行为。

## `call` 方法

函数的 `call` 方法允许你调用函数，并修改本次调用时函数内的 `this` 指向。其类型声明如下：

```TypeScript
// 这里的 Func 泛型表示原函数本身的类型
function call(thisArg: any, ...params: Parameters<Func>): ReturnType<Func>
```

其中 `thisArg` 表示本次调用的 `this` 指向，`...params` 表示传递给原函数的参数，用代码简单表示的话如下：

```TypeScript
function myFunc(...params: any[]): any;

myFunc.call(thisArg, ...params);
// 相当于：
this = thisArg;
myFunc(...params);
```

例如：

```TypeScript
interface Addable {
    y: number;
}

function myFunc<T extends Addable>(this: T, x: number): number {
    this.y += x;
    return this.y;
}

// 第一个对象
const a = { y: 100 };
// 第二个对象
const b = {
    y: 10,
    someMethod() { ... }
}

myFunc.call(a, 10); // a.y 变成 110，这句话返回 110
myFunc.call(b, 10); // b.y 变成 20，这句话返回 20
```

注意在使用 ts 时，函数声明的参数中写 `this` 并不表示参数，而表示函数的 `this` 指向，也就是说 `myFunc` 只有一个参数 `x`，而不是两个参数，因此后面的 `myFunc.call` 的参数列表只需要填一个。

需要注意的是，箭头函数不包含 `this` 指向，这也意味着它不能使用 `call` 方法。

## `apply` 方法

`apply` 方法与 `call` 方法的功能完全一样，唯一的区别是二者的参数不一致：

```TypeScript
function apply(thisArg: any, params: Parameters<Func>): ReturnType<Func>;
```

其中 `thisArg` 表示本次调用的 `this` 指向，`params` 表示传递给原函数的参数，注意这里与 `call` 不同，`call` 是剩余参数，而 `apply` 是数组。

依然使用上面的 `myFunc` 作为示例：

```TypeScript
myFunc.apply(a, [10]); // 等同于 myFunc.call(a, 10)，参数要使用数组
myFunc.apply(b, [10]); // 等同于 myFunc.call(b, 10)
```

## `bind` 方法

`bind` 方法用于创建一个新函数，调用时会以指定 `this` 调用原函数。其类型声明如下：

```TypeScript
function bind<T>(thisArg: T): (this: T, ...params: Parameters<Func>) => ReturnType<Func>;
```

其中 `thisArg` 表示新函数的 `this` 指向。

还是以 `myFunc` 作为示例：

```TypeScript
const newFuncA = myFunc.bind(a); // newFuncA 内容还是 myFunc，但是 this 指向变为了 a
newFuncA(10); // a.y 变成 110，返回 110
const newFuncB = myFunc.bind(b); // newFuncB 内容还是 myFunc，但是 this 指向变为了 b
newFuncB(10); // b.y 变成 20，返回 20
```

## 其他内容

`call` `apply` `bind` 本身也是函数，因此他们也有 `call` `apply` `bind` 方法。以 `call` 为例，你可以使用 `func.call.call()` 来修改 `func.call` 的 `this` 指向。`call` 的 `this` 指向默认为原函数（可以想想为什么），当对 `call` 执行 `call` 时，就会修改原函数，相当于直接调用了另外一个函数了。例如：

```TypeScript
function funcA() {
    console.log('Called funcA');
}
function funcB() {
    console.log('Called funcB');
}
// 第一个参数 funcB 表示 funcA.call 的 this 指向，
// 第二个参数 void 0 表示传递给 funcA.call 的第一个参数，
// 也就是传递给 funcB（本来应该是 funcA，但是 this 绑定为了 funcB）的 this 指向
funcA.call.call(funcB, void 0); // 输出 Called funB
```

当然这没有什么实际用途，只能用于加深对 js 的理解。

# 5.3.5 函数转字符串

可以使用 `toString` 将函数转换为字符串。此行为可以用于代码调试，在实际项目中很少出现：

```TypeScript
function sum(a, b) {
  return a + b;
}

console.log(sum.toString());
// Expected output: "function sum(a, b) {
//                     return a + b;
//                   }"
```

# 5.3.6 函数属性

函数上还包括一些属性，这些属性多用于调试和日志输出，很少用于代码逻辑。

## `length` 属性

函数的 `length` 属性表示函数预期接收的参数数量，剩余参数不算在内，不计算第一个默认参数及之后的参数。例如：

```TypeScript
console.log((() => {}).length); // 0
console.log(((a) => {}).length); // 1
console.log(((a, b) => {}).length); // 2，依此类推

console.log(((...args) => {}).length);
// 0，剩余参数不计算在内

console.log(((a, b = 1, c) => {}).length);
// 1，只计算第一个具有默认值的参数之前的参数
```

## `name` 属性

函数的 `name` 属性表示了函数的名称，如果函数是匿名函数则会返回空字符串或者 `anonymous`。此属性的具体行为比较复杂，如果想要了解的话可以参考 [Function.name - JavaScript | MDN](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference/Global_Objects/Function/name)。
