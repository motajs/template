# 6.11.2 纹理操作

## 创建纹理

我们使用 `gl.createTexture` 创建纹理：

```TypeScript
function createTexture(): WebGLTexture;
```

例如：

```TypeScript
const texture = gl.createTexture();
```

## 激活与绑定纹理

接下来，我们需要告诉 `WebGL2` 我们需要操作哪个纹理，以及纹理存放在哪个地方。

首先我们需要调用 `gl.activeTexture` 来激活一个纹理：

```TypeScript
function activeTexture(texture: number): void;
```

我们使用 0 号纹理，传入 `gl.TEXTURE0`：

```TypeScript
gl.activeTexture(gl.TEXTURE0);
```

然后我们需要调用 `gl.bindTexture` 让 `WebGL2` 知道我们需要操作的是哪个纹理对象：

```TypeScript
function bindTexture(target: GLenum, texture: WebGLTexture): void;
```

我们使用二维纹理，因此传入 `gl.TEXTURE_2D`，其他类型的纹理我们在后面的课程中讲解。

```TypeScript
gl.bindTexture(gl.TEXTURE_2D, texture);
```

这样，我们就会操作我们刚刚定义的 `texture` 纹理对象，它被绑定到了二维纹理，同时我们激活了 0 号纹理，因此我们对它的操作会自动传入 0 号纹理。最终的结果就是，我们定义了一个二维纹理，并把它绑定到了 0 号纹理。

这里的逻辑比较绕，相比于缓冲区它还多了一层绑定，相当于绑定了两次。

## 传输纹理

接下来我们需要把图片传递给纹理对象，使用 `texImage2D`，我们最常用的是这个用法：

```TypeScript
function texImage2D(
    target: GLenum,
    level: number,
    internalFormat: GLenum,
    format: GLenum,
    type: GLenum,
    pixels: TexImageSource
): void;
```

- `target`：要把图片传递给绑定的纹理对象。
- `level`：图片的金字塔简化级别。这个我们之后的课程中讨论，本节不讨论。
- `internalFormat`：图片的内部存储格式，常使用 `gl.RGBA`，其他值在部分情况下也可能会使用。
- `format`：图像源的读取方式，常使用 `gl.RGBA`，它会读取四个通道，如果填写 `gl.RGB`，那么会抛弃不透明度通道，只保留颜色通道。其他格式使用较少。一般与 `internalFormat` 保持一致。
- `type`：数据类型，常使用 `gl.UNSIGNED_BYTE` 表示八位色深的图片。
- `pixels`：图像源，可以是 `TypedArray` `HTMLCanvasElement` `HTMLImageElement` 等。

我们的示例中使用 `HTMLImageElement` 作为图像源，格式为 `gl.RGBA`，数据类型为 `gl.UNSIGNED_BYTE`，因此：

```TypeScript
gl.activeTexture(gl.TEXTURE0);
gl.bindTexture(gl.TEXTURE_2D, texture);
gl.texImage2D(gl.TEXTURE_2D, 0, gl.RGBA, gl.RGBA, gl.UNSIGNED_BYTE, img);
```

一般我们会使用宽高为2的幂次的图像，例如 `1024*1024` `512*256` 等，这种图像会帮助 `WebGL2` 内部优化，性能表现会更好。不是这些大小的纹理依然可以使用（`WebGL` 不行，只有 `WebGL2` 可以）。

## 性能问题

使用 `WebGL2` 画图片确实很快，但是如果去尝试的话会发现耗时远比 `Canvas2D` 更长，这不是因为 `WebGL2` 画图片的速度更慢，而是因为时间都花费在了图片的传递上，也就是说把图片传递给 GPU 是个很慢的操作。关于这个问题，我们在之后将会有几节课专门讲解。

# 6.11.3 纹理参数

我们会使用 `gl.texParameteri` 来控制部分纹理参数：

```TypeScript
function texParameteri(texture: GLenum, param: GLenum, value: GLenum): void;
```

## 缩放参数

缩放参数包含两个 `gl.TEXTURE_MAG_FILTER` 和 `gl.TEXTURE_MIN_FILTER`，分别代表放大参数与缩小参数。它们都可以填这两个参数：

- `gl.NEAREST`：取最近的采样点，即当前点距离纹理的哪个像素最近取哪个。
- `gl.LINEAR`：取周围的采样点，并执行线性插值操作，相当于有简易的抗锯齿。

其他值我们本节课接触不到，暂时不讲解。

我们的图片不是像素风图片，这时候一般建议使用 `gl.LINEAR`：

```TypeScript
gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MAG_FILTER, gl.LINEAR);
gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MIN_FILTER, gl.LINEAR);
```

## 边缘参数

边缘参数指的是如果读取了在纹理范围之外的坐标，会有什么行为。如图所示：

- `gl.REPEAT`：超出部分重复纹理。

我们可以分别设置横坐标上的边缘参数与纵坐标上的边缘参数：

```TypeScript
gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_WRAP_S, gl.CLAMP_TO_EDGE);
gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_WRAP_T, gl.CLAMP_TO_EDGE);
```

# 6.11.4 着色器

## `sampler2D` 数据类型

贴图需要使用 `sampler2D` 数据类型，我们需要在片段着色器里面定义一个 `uniform` 变量：

```OpenGL Shading Language
uniform sampler2D u_sampler;
```

这个数据类型描述了贴图的采样器，即用来读取贴图。它本质上是一个数字，存储了要读取的纹理编号。我们先前提到的纹理编号，对应到着色器就是这个数据类型。

我们使用的是 0 号纹理，因此我们需要给它赋值为 0：

```TypeScript
const location = gl.getUniformLocation('u_sampler');
gl.uniform1i(location, 0);
```

## 纹理读取

纹理的坐标与 `WebGL2` 的世界坐标并不一样。对于纹理，左上角坐标是 `(0,0)`，右上角坐标是 `(1,0)`，左下角坐标是  `(0,1)`，右下角坐标是 `(1,1)`，也就是与 `Canvas2D` 的坐标模式一致。

读取纹理使用 `texture` 接口，它会返回一个 `vec4` 四维向量，包含了 `RGBA` 通道：

```OpenGL Shading Language
outColor = texture(u_sampler, coord);
```

那么我们需要考虑一个问题，这里的第二个参数 `coord` 坐标该怎么填？

还记得之前讲过的插值吗，我们可以利用插值来填写坐标。我们可以在顶点着色器内定义一个纹理坐标输入和输出：

```OpenGL Shading Language
in vec2 a_texCoord;
out vec2 v_texCoord;
```

然后传递给片段着色器：

```OpenGL Shading Language
v_texCoord = a_texCoord;
```

这样的话，传递给片段着色器的坐标就是经过插值的。我们只需要控制纹理坐标输入，让它在左上角的顶点值为 `(0,0)`，右上角的顶点值为 `(1,0)`... 就可以让贴图画出来了。

这样的话，片段着色器中的读取贴图就是：

```OpenGL Shading Language
outColor = texture(u_sampler, v_texCoord);
```

## 顶点着色器

我们编写顶点着色器如下：

```OpenGL Shading Language
#version 300 es
precision highp float;

in vec4 a_position;
in vec2 a_texCoord;

out vec2 v_texCoord;

void main() {
  v_texCoord = a_texCoord;
  gl_Position = a_position;
}
```

## 片段着色器

我们编写片段着色器如下：

```OpenGL Shading Language
#version 300 es
precision highp float;

in vec2 v_texCoord;
out vec4 outColor;

uniform sampler2D u_sampler;

void main() {
  outColor = texture(u_sampler, v_texCoord);
}
```

# 6.11.5 顶点坐标

根据上面的讨论，我们可以编写顶点坐标如下，使用 `gl.TRIANGLE_STRIP` 连接方式：

```TypeScript
const array = new Float32Array([
  1.0, 1.0,   1.0, 0.0, // 右上角
  -1.0, 1.0,  0.0, 0.0, // 左上角
  1.0, -1.0,  1.0, 1.0, // 右下角
  -1.0, -1.0, 0.0, 1.0, // 左下角
]);
```

每一行的前两个数代表顶点坐标，后两个数代表纹理坐标。

因此传递顶点数组如下：

```TypeScript
// 顶点赋值给缓冲区
const buffer = gl.createBuffer();
gl.bindBuffer(gl.ARRAY_BUFFER, buffer);
gl.bufferData(gl.ARRAY_BUFFER, array, gl.STATIC_DRAW);

// 传递并启用顶点数组
const position = gl.getAttribLocation(program, 'a_position');
gl.vertexAttribPointer(position, 2, gl.FLOAT, false, 4 * 4, 0);
gl.enableVertexAttribArray(position);

// 传递并启用颜色数组
const tex = gl.getAttribLocation(program, 'a_texCoord');
gl.vertexAttribPointer(tex, 2, gl.FLOAT, false, 4 * 4, 2 * 4);
gl.enableVertexAttribArray(tex);
```

# 6.11.6 执行渲染

我们在图片加载完毕后执行渲染，编写 `drawScene` 函数：

```TypeScript
const drawScene = () => {
  gl.activeTexture(gl.TEXTURE0);
  gl.bindTexture(gl.TEXTURE_2D, texture);
  gl.texImage2D(gl.TEXTURE_2D, 0, gl.RGBA, gl.RGBA, gl.UNSIGNED_BYTE, img);
  
  // 设置纹理参数
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MAG_FILTER, gl.LINEAR);
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MIN_FILTER, gl.LINEAR);
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_WRAP_S, gl.CLAMP_TO_EDGE);
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_WRAP_T, gl.CLAMP_TO_EDGE);
  
  gl.uniform1i(sampler, 0);
  
  gl.clearColor(0, 0, 0, 1);
  gl.clearDepth(1);
  gl.clear(gl.COLOR_BUFFER_BIT | gl.DEPTH_BUFFER_BIT);

  // 执行渲染
  gl.drawArrays(gl.TRIANGLE_STRIP, 0, 4);
}
```

在图片加载完成后调用：

```TypeScript
img.addEventListener('load', () => {
  drawScene();
});
```

# 6.11.7 完整代码

顶点着色器与片段着色器已经在前面给出。以下是 `TypeScript` 内容：

```TypeScript
const imgSrc = 'https://cdn.jsdelivr.net/gh/unanmed/h5-programming-training/img/5.11.webp';
const img = new Image();
img.src = imgSrc;
img.crossOrigin = '';

// 创建画布
const canvas = document.querySelector("#webgl");
const gl = canvas.getContext("webgl2")!;

//设置画布宽高
canvas.width = 300 * devicePixelRatio;
canvas.height = 300 * devicePixelRatio;

// 顶点着色器已经在上面给出
const vs = /* glsl */ `
`;

// 片段着色器已经在上面给出
const fs = /*glsl */ `
`;

// 编译着色器
const vsShader = compileShader(gl.VERTEX_SHADER, vs)
const fsShader = compileShader(gl.FRAGMENT_SHADER, fs);

// 创建程序并编译链接
const program = gl.createProgram();
gl.attachShader(program, vsShader);
gl.attachShader(program, fsShader);
gl.linkProgram(program);

// 如果程序链接失败
if (!gl.getProgramParameter(program, gl.LINK_STATUS)) {
  const info = gl.getProgramInfoLog(program);
  throw new Error(`无法编译 WebGL 程序。\n\n${info}`);
}

// 定义顶点数组和颜色数组
const array = new Float32Array([
  1.0, 1.0,   1.0, 0.0, // 右上角
  -1.0, 1.0,  0.0, 0.0, // 左上角
  1.0, -1.0,  1.0, 1.0, // 右下角
  -1.0, -1.0, 0.0, 1.0, // 左下角
]);

// 顶点赋值给缓冲区
const buffer = gl.createBuffer();
gl.bindBuffer(gl.ARRAY_BUFFER, buffer);
gl.bufferData(gl.ARRAY_BUFFER, array, gl.STATIC_DRAW);

// 传递并启用顶点数组
const position = gl.getAttribLocation(program, 'a_position');
gl.vertexAttribPointer(position, 2, gl.FLOAT, false, 4 * 4, 0);
gl.enableVertexAttribArray(position);

// 传递并启用颜色数组
const tex = gl.getAttribLocation(program, 'a_texCoord');
gl.vertexAttribPointer(tex, 2, gl.FLOAT, false, 4 * 4, 2 * 4);
gl.enableVertexAttribArray(tex);

// 创建纹理对象
const texture = gl.createTexture();

// uniform 变量地址
const sampler = gl.getUniformLocation(program, 'u_sampler');

// 使用着色器程序
gl.useProgram(program);

// 设置视口
gl.viewport(0, 0, canvas.width, canvas.height);
gl.disable(gl.CULL_FACE);

// 传递纹理并绘制
const drawScene = () => {
  gl.activeTexture(gl.TEXTURE0);
  gl.bindTexture(gl.TEXTURE_2D, texture);
  gl.texImage2D(gl.TEXTURE_2D, 0, gl.RGBA, gl.RGBA, gl.UNSIGNED_BYTE, img);
  
  // 设置纹理参数
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MAG_FILTER, gl.LINEAR);
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MIN_FILTER, gl.LINEAR);
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_WRAP_S, gl.CLAMP_TO_EDGE);
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_WRAP_T, gl.CLAMP_TO_EDGE);
  
  gl.uniform1i(sampler, 0);
  
  gl.clearColor(0, 0, 0, 1);
  gl.clearDepth(1);
  gl.clear(gl.COLOR_BUFFER_BIT | gl.DEPTH_BUFFER_BIT);

  // 执行渲染
  gl.drawArrays(gl.TRIANGLE_STRIP, 0, 4);
}

img.addEventListener('load', () => {
  drawScene();
});

/**
 * 编译着色器
 * @param type 着色器类型
 * @param source 着色器代码
 */
function compileShader(type: GLenum, source: string): WebGLShader {
  const shader = gl.createShader(type);
  gl.shaderSource(shader, source);
  gl.compileShader(shader);
  
  // 如果编译失败
  if (!gl.getShaderParameter(shader, gl.COMPILE_STATUS)) {
    const info = gl.getShaderInfoLog(shader);
    throw new Error(`无法编译着色器。\n\n${info}`);
  }
  
  return shader;
}
```
