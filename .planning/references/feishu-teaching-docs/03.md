在讲解 `WebGL2` 基本概念之前，我们必须先来讲解一下类型化数组这一概念。

与上节课相比，本节课的强度没那么高，会更好理解一些。

# 6.5.1 基本概念

类型化数组是一类纯数字数组，拥有固定的数据类型，它会在内存中连续存储，因此性能会比传统的数组更好（根据 benchmark，类型化数组的性能约为普通数组的两倍），但是它也有较大局限性，一般只会在性能敏感条件下或是二进制数据处理时使用。

类型化数组包含多个类型，其用法完全一致，区别只在于数据类型。常用的包括：

- `Int8Array`：每个数据都是一个 8 位有符号整数，范围 `-128 ~ 127`。
- `Uint8Array`：每个数据都是一个 8 位无符号整数，范围 `0 ~ 255`，是最常用的类型化数组之一。
- `Uint8ClampedArray`：每个数据都是一个 8 位无符号整数，范围 `0 ~255`，与 `Uint8Array` 有一定的区别，不常用。区别会在后面讲解到。
- `Int16Array`：每个数据都是一个 16 位有符号整数，范围 `-32768 ~ 32767`。
- `Uint16Array`：每个数据都是一个 16 位无符号整数，范围 `0 ~ 65535`。
- `Int32Array`：每个数据都是一个 32 位有符号整数，范围 `-2147483647 ~ 2147483648`。
- `Uint32Array`：每个数据都是一个 32 位无符号整数，范围 `0 ~ 4294967295`。
- `Float32Array`：每个数据都是一个 32 位浮点数，7 位有效数字，范围 `-3.4E38` 到 `3.4E38`，最小的正数是`1.2E-38`。是最常用的类型化数组之一。
- `Float64Array`：每个数据都是一个 64 位浮点数，16 位有效数字，范围 `-1.8E308` 到 `1.8E308`，最小的正数是 `5E-324`。

这些类型化数组都有规律，记住一个就可以类比出其他的。必须掌握的是 `Float32Array` 和 `Uint8Array`，它们将会在后续大量使用到。

## 约定

后续内容中，将会大量使用十六进制的数据，因为两个十六进制数据刚刚好对应 `Uint8` 类型，`0x00` 为 0，`0xFF` 为 255。

# 6.5.2 长度

类型化数组包含两个长度，一个是数组长度，另一个是字节长度。其中数组长度很好理解，就是数组包含多少个数字。

对于字节长度，要看数组的数据类型。每 8 位是一个字节，因此容易推断出每一种数据类型的字节长度如下：

| 数据类型 | 字节长度 | 数组字节长度 |
|-|-|-|
| `Int8` `Uint8` | 1 | `1 * length` |
| `Int16` `Uint16` | 2 | `2 * length` |
| `Int32` `Uint32` `Float32` | 4 | `4 * length` |
| `Float64` | 8 | `8 * length` |

需要注意的是，类型化数组的长度是不可变的，其长度会在数组定义时确定，之后不可变。

# 6.5.3 创建类型化数组的基础方法

创建类型化数组的方法很多，但是我们目前只能讲解三种方法。

## 使用 `new` 直接创建

使用 `new` 创建类型化数组，并指定长度：

```TypeScript
function TypedArray(length: number): TypedArray;
```

示例如下：

```TypeScript
const array1 = new Uint8Array(16); // 创建一个 16 长度的 Uint8 类型化数组
array1[2] = 16; // 给第三项赋值为 16
array1[4] = 0x5C; // 给第五项赋值为 0x5C
const array2 = new Float32Array(32); // 创建一个 32 长度的 Float32 类型化数组
array2[31] = 1.23456; // 给最后一项赋值为 1.23456
```

如果不填写 `length` 参数，那么会创建一个长度为 0 的类型化数组。

## 通过数组创建

除了直接指定长度，还可以通过传入一个传统数组来创建类型化数组。例如：

```TypeScript
const array1 = new Float32Array([1.1, 2.2, 3.3, 4.4]); // 创建一个长度为 4 的类型化数组
const array2 = new Uint8Array([1, 2, 3, 4]); // 创建一个长度为 4 的类型化数组
```

## 通过类型化数组创建

我们还可以直接指定一个类型化数组来创建，此操作会将类型化数组复制一份，并对数据类型进行数值转换。数值转换遵循数值相同原则，如果是浮点数向整数的转换，那么会向下取整。示例如下：

```TypeScript
const array1 = new Uint8Array([1, 2, 3, 4]); // 创建一个长度为 4 的类型化数组
const array2 = new Uint8Array(array1); // 复制一份
const array3 = new Uint16Array(array2); // 复制为 Uint16Array
```

# 6.5.4 数据截断

如果你给整数类型化数组赋值了一个超出数据类型范围的值，那么将对数据截断。具体来说：

对于 `Uint8ClampedArray`，将会钳制在 `0-255` 范围内，即小于 0 的数转换为 0，大于 255 的数转换为 255。

对于其他整数数组，将会直接截断高位，例如在 `Uint8Array` 中，赋值为 `256 = 0x100`，那么将会截断成 `0x00 = 0`，赋值为 `1234 = 0x4D2`，那么会截断成 `0xD2 = 210`，赋值为 `-20 = 0xF...EC`，那么将会截断成 `0xEC = 236`。

对于 `Float32Array`，超出范围的浮点数会存储为 `Infinity`，对于不超出范围的浮点数，将会通过算法将 `js` 使用的 64 位浮点数转换至最接近的 32 位浮点数。

# 6.5.5 字节序

字节序描述了计算机存储数据类型的方式，分为大字端与小字端。小字端表明数据是按照字节从低到高的顺序存储的，也是大部分设备与平台使用的存储方式；大字端表明数据是按照字节从高到低的顺序存储的，不那么常用。

举例来说，对于一个 32 位数据，例如 `0x12345678`，按照小字端存储时，每个字节将会存储为 `0x78 0x56 0x34 0x12`，按照大字端存储时，将会存储为 `0x12 0x34 0x56 0x78`。

小字端常用是因为使用这种存储方式时，如果数据较小，例如使用 32 位存储了 8 位，那么高位会全是 0，此时就可以省略高位，从而减小存储体积。

# 6.5.6 缓冲区

缓冲区描述了一个类型化数组的实际存储的内容的部分，内部是二进制数据，不能直接读取，需要使用类型化数组接收并读取。

缓冲区使用接口 `ArrayBuffer`，它仅包含字节长度，不包含数组长度，因为它实际上并不是一个数组，而是存储在内存的一系列连续数据。

## 获取缓冲区

我们可以获取类型化数组的缓冲区：

```TypeScript
const array1 = new Uint8Array(8); // 定义类型化数组
const buffer = array1.buffer; // 获取缓冲区
```

## 从缓冲区创建类型化数组

我们可以通过缓冲区来创建类型化数组。例如：

```TypeScript
const array1 = new Uint8Array(8); // 定义类型化数组
const buffer = array1.buffer; // 获取缓冲区
const array2 = new Uint8Array(buffer); // 从缓冲区创建类型化数组
```

使用这种方式时，可以在不同数据类型之间转换，其转换规则遵循 5.5.5 小节中讲到的字节序，一般是小字端。举例来说，对于一串二进制数据 `0x12 0x34 0x56 0x78`，使用 `Uint8Array` 获取时，类型化数组将会是 `[0x12, 0x34, 0x56, 0x78]`，如果使用 `Uint16Array` 获取，类型化数组将会是 `[0x3412, 0x7856]`。如果使用浮点数创建，那么遵循 `IEEE 754` 浮点数规则。示例如下：

```TypeScript
const array1 = new Uint8Array([0x12, 0x34, 0x56, 0x78]);
const buffer = array1.buffer;
const array2 = new Uint32Array(buffer); // 使用 32 位整数
array2[0]; // 0x78563412
```

## 内存共享

对于引用了同一个 `ArrayBuffer` 的类型化数组，其使用同一个缓冲区，因此内存也是共享的，当一个类型化数组变化时，其他的也会同步改变：

```TypeScript
const array1 = new Uint8Array([0x12, 0x34, 0x56, 0x78]);
const buffer = array1.buffer;
const array2 = new Uint32Array(buffer); // 使用 32 位整数
array1[2] = 0x00;
array2[0]; // 0x78560012;
array2[0] = 0x12345678;
array1; // [0x78, 0x56, 0x34, 0x12]
```

## 字节偏移与长度

在使用 `ArrayBuffer` 创建类型化数组时，可以指定字节偏移与长度。具体来说，类型化数组会从指定的偏移位置开始读取，然后读取指定长度的字节，并构建为类型化数组。举例来说：

```TypeScript
const array1 = new Uint8Array([0x12, 0x34, 0x56, 0x78]);
const array2 = new Uint8Array(array1.buffer, 1, 2); // 偏移为 1，长度为 2
array2; // [0x34, 0x56]，从偏移一个字节的位置开始读取，读取两个字节
```

注意，这里的偏移与长度都是字节偏移与长度，并非数组的偏移与长度，例如使用 `Uint16Array` 创建时：

```TypeScript
const array1 = new Uint16Array([0x1234, 0x3456, 0x5678, 0x789A]);
const array2 = new Uint8Array(array1.buffer, 1, 4); // 偏移为 1，长度为 2
array2; // [0x12, 0x56, 0x34, 0x78]，从偏移一个字节的位置开始读取，读取四个字节
```

## 关于修改长度

在新标准中，可以通过 `ArrayBuffer.resize` 来调整缓冲区的字节长度，但是由于其对浏览器版本要求高，兼容性差，并不推荐使用。

# 6.5.7 类型化数组方法

类型化数组包含大部分数组也包含的方法，正好复习一遍之前的内容：

- `at`：获取数组某一项的值，可以填入负数表示从末尾获取。
- `copyWithin`：这个之前没讲过，马上讲，普通数组也有这个方法，但是相对不常用。
- `every`：判断是否每一项都满足条件。
- `fill`：将数组全部填充为某个值。
- `filter`：对数组每一项判断是否满足条件，将满足条件的数据单独组成一个新的类型化数组。
- `find` `findIndex` `findLast` `findLastIndex`：根据条件获取符合条件的项。
- `forEach`：遍历数组。
- `includes`：判断数组是否包含某个数据。
- `indexOf` `lastIndexOf`：获取指定数据的索引位置。
- `join`：在每个数据之间插入字符串并将整体合并为一个字符串。
- `map`：对数组进行遍历，并将每一项映射为一个新的值，新值组成一个新的类型化数组。
- `reduce` `reduceRight`：数组求和。
- `reverse`：翻转类型化数组，并非简单的指针反向，缓冲区的数据也会同时反向。
- `slice`：裁剪数组，将结果组成一个新的类型化数组。
- `some`：判断数组中是否至少有一项满足条件。
- `sort`：数组排序。

## `set` 方法

`set` 方法提供了一种高效的设置类型化数组的值的方法，它要求传入一个数组或类型化数组，并指定偏移量，方法将会把传入数组拷贝至目标数组指定偏移量的位置。这里的偏移量并非字节偏移量，而是下标偏移量。方法的类型声明如下：

```TypeScript
function set(array: Array | TypedArray, targetOffset?: number): void;
```

示例如下：

```TypeScript
const array = new Uint8Array([0x00, 0x12, 0x11, 0x22, 0x33]);
array.set([0x40, 0x50], 2); // array 会变成 [0x00, 0x40, 0x50, 0x22, 0x33]
```

这种方式的性能远比手动循环赋值更快，因此多数情况下更推荐使用这种方式。

如果传入的类型化数组与目标数组使用同一 `ArrayBuffer`，那么将会直接进行拷贝，速度更快。

## `copyWithin` 方法

`copyWithin` 方法提供了一种高效的在数组内拷贝数据的方法。其类型声明如下：

```TypeScript
function copyWithin(target: number, start: number, end?: number): void;
```

`target` 表示要将数据拷贝至那个地方，`start` 表示数据开始拷贝的下标，`end` 表示数据结束拷贝的下标。方法会将从 `start` 下标至 `end` 下标（不填时表示结尾）区间的内容拷贝至 `target` 开始的区域。拷贝的区域允许重合。举例来说：

```TypeScript
const array = new Uint8Array([0x00, 0x12, 0x11, 0x22, 0x33]);
array.copyWithin(3, 0, 2); // [0x00, 0x12, 0x11, 0x00, 0x12] 将前两项拷贝至下标 3 开头的地方
array.copyWithin(1, 0, 4); // [0x00, 0x00, 0x12, 0x11, 0x00] 将前四项拷贝至下标 1 开头的地方
```

## `subarray` 方法

`subarray` 方法用于提取类型化数组的子数组，同时与原数组共用同一 `ArrayBuffer`，共用同一内存。

```TypeScript
function subarray(start: number, end?: number): TypedArray
```

其中 `start` 表示裁剪起始索引，`end` 表示裁剪结尾索引，裁剪结果不包含此索引，不填表示裁剪至末尾。由于此方法不会创建新的内存缓冲区，因此速度极快，可以方便地将一个长数组分割为多个短数组，便于维护和操作。例如我们将一个 64 长度的数组分割为四个 16 长度的数组：

```TypeScript
const array = new Float32Array(64);
const array1 = array.subarray(0, 16);
const array2 = array.subarray(16, 32);
const array3 = array.subarray(32, 48);
const array4 = array.subarray(48, 64);
```
