**源码事实（写作时逐条核对，勿凭印象）：**
- `FaceDirection`（`packages-user/data-common/src/common/types.ts`）是 `const enum`，顺序为 `Unknown`、`Left`、`Up`、`Right`、`Down`、`LeftUp`、`RightUp`、`LeftDown`、`RightDown`。文档不要教读者按数值硬编码。
- `FaceGroup`（`faceManager.ts`）是 `const enum`：`Dir4`、`Dir8`。
- `IFaceHandler`（`packages/common/src/utils/types.ts`）八个方法，注释原文要点：`degrade` 把任意朝向降级为本组支持的方向，无法合理降级（含 `Unknown`）返回 `Unknown`；`movement` 返回单步偏移，输入先经过 `degrade`；`move(dir, count)` 等价于偏移乘 `count`，`count` 可为负，输入先经过 `degrade`；`opposite` 返回本组内反方向，`Unknown` 返回 `Unknown`，输入先经过 `degrade`；`next(dir, anticlockwise)` 在本组内顺时针（默认）或逆时针旋转一步，输入先经过 `degrade`，`Unknown` 返回 `Unknown`；`dirOf(dx, dy)` 返回对应偏移量的朝向，有多个符合时返回其中一个；`mapDirection` 迭代本组所有朝向（含 `Unknown`）；`mapMovement` 迭代本组所有朝向及其偏移（含 `Unknown` 对应 `{ x: 0, y: 0 }`）。
- `IFaceDescriptor` 是只读的 `{ x, y }`；`IRayRangeParam.dir` 就是 `IFaceDescriptor` 列表。
- `Dir8FaceHandler`：`degrade` 原样返回；运动表覆盖八方向 + `Unknown`；`opposite` / `next` 用独立映射表，查不到返回 `Unknown`。
- `Dir4FaceHandler`：`degrade` 的映射是 `Left` / `Up` / `Right` / `Down` 原样，`LeftUp` / `LeftDown` → `Left`，`RightUp` / `RightDown` → `Right`，其余（含 `Unknown`）→ `Unknown`；运动表只含四方向 + `Unknown`。
- `dirOf` 的实现会遍历一张方向表并返回第一个匹配；**不要**在文档里断言 `Dir4FaceHandler.dirOf` 对斜向偏移的具体返回（源码使用的表与 `degrade` 语义可能不一致）。若核对时确认不一致，只向用户报告，不写进文档、不记录为问题（AGENTS.md / D-72）。
- `FaceManager`（`faceManager.ts`）实现 `IFaceManager`：`register(group, handler)`、`registerById(id, handler)`、`get(group)`、`getById(id)`；后两者找不到返回 `null`。
- 注册位置：`src/data/initialize.ts` 里 `state.faceManager.register(FaceGroup.Dir4, dir4)`、`registerById('dir4', dir4)`、`register(FaceGroup.Dir8, dir8)`、`registerById('dir8', dir8)`。
- `data-base/src/shared.ts` 的 `HERO_MOVER_FACE` 与 `DYNAMIC_MOVER_FACE` 都是 `FaceGroup.Dir8`；`DynamicTileMover` 构造时用 `face.get(DYNAMIC_MOVER_FACE)!` 取处理器，`DynamicTile.getCurrentFaceDirection()` 则用 `layer.faceBinder.getFaceDirection(tileNum)`。
- `IRoleFaceBinder`（`common/types.ts`）：`malloc(identifier, main)` 分配主朝向（注释：主朝向一般是朝下）；`bind(identifier, main, face)` 把一个图块与主图块绑定朝向，注释明确要求先 `malloc`；`getFaceOf(identifier, face)` 返回 `IFaceData | null`；`getFaceDirection(identifier)` 没有数据时返回 `Unknown`；`getMainFace(identifier)` 返回 `IFaceData | null`。实现类 `RoleFaceBinder` 在 `face.ts`；`bind` 时主图块未 `malloc` 或朝向与主朝向相同会报错并放弃绑定。
