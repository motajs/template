## 错误码映射（82–95，唯一依据）

`logger.error(code, ...params)` 的 `params` 类型是 `string[]`：所有数字实参必须先 `.toString()`，或在模板字符串里拼接。下表 message 为 `logger.json` 中的最终文本（`$n` 为占位符）。

| code | 类别 | message |
|------|------|---------|
| 82 | 缓冲区过短 | `Cannot parse animation: buffer is too short, got $1 bytes while the $2 byte header is required.` |
| 83 | 签名无效 | `Cannot parse animation: invalid signature 0x$1, expected 0x$2.` |
| 84 | 版本不支持 | `Cannot parse animation: unsupported version $1, expected version $2.` |
| 85 | 长度字段 / 总长度不符 | `Cannot parse animation: data length mismatch, imageDataSize: $1, metaDataSize: $2, buffer length: $3.` |
| 86 | sprite 数量 / 尺寸 | `Cannot parse animation: $1.` |
| 87 | 位图数量 / 字段 / 越界 | `Cannot parse animation: $1.` |
| 88 | 帧结构（非数组 / 非对象 / 元组元数 5–7） | `Cannot parse animation: $1.` |
| 89 | 对象索引 | `Cannot parse animation: invalid object index $1 at frame $2, expected an integer in [0, $3).` |
| 90 | 对象字段（x / y / scale / opacity / mirror / rotate） | `Cannot parse animation: $1.` |
| 91 | ratio | `Cannot parse animation: invalid ratio $1, expected a positive finite number.` |
| 92 | blend | `Cannot parse animation: invalid blend mode $1, expected 0 (normal) or 1 (add).` |
| 93 | 音效字段 | `Cannot parse animation: $1.` |
| 94 | 元数据 JSON 解析失败 | `Cannot parse animation: cannot parse metadata JSON. $1` |
| 95 | 图像解码 / 纹理创建失败 | `Cannot parse animation: cannot decode image or create texture. $1` |

**`$1` 明细串（86 / 87 / 88 / 90 / 93）的固定写法（同一错误码覆盖同类多项检查，明细由调用点用模板字符串给出）：**

| code | 明细串示例 |
|------|-----------|
| 86 | `sprite count 0 is not allowed` / `sprite 1 has invalid size 0 x 32` / `sprite table of 3 sprites exceeds imageDataSize 12` |
| 87 | `bitmap list is not an array` / `bitmap count 2 does not match sprite count 1` / `bitmap 0 is not an object` / `bitmap 0 has invalid x -1` / `bitmap 0 (x: 0, y: 0, width: 32, height: 32) exceeds the decoded image 16 x 16` |
| 88 | `frame list is not an array` / `frame 0 is not an object` / `objects of frame 0 is not an array` / `object 0 of frame 0 is not a tuple` / `object 0 of frame 0 has 4 fields, expected 5 to 7` / `sound of frame 0 is not an array` |
| 90 | `object 0 of frame 0 has invalid x: NaN` / `object 0 of frame 0 has invalid scale: 0, expected a positive number` / `object 0 of frame 0 has invalid opacity: 300, expected a number in [0, 255]` |
| 93 | `sound 0 of frame 0 is not an object` / `sound 0 of frame 0 has invalid name` / `sound 0 of frame 0 has invalid volume: NaN` / `sound 0 of frame 0 has invalid pitch: NaN` |

**94 / 95 的 `$1` 来源：** 94 的 `$1` 固定为 `metadata is not valid JSON`（脱敏常量，**不读取 `error.message`**，避免 `JSON.parse` 的异常文本回显元数据内容）；95 的 `$1` 为解码 / 纹理异常的 `error.message`（`error instanceof Error ? error.message : String(error)`）。

## `parse.ts` 改写规格（逐函数）

**导入与分区：** 在第 1 行新增 `import { logger } from '@motajs/common';`，其后保持现有 `./types` 与 `@motajs/render` 两行顺序不变；所有 import 连续、中间不夹注释或空行。现有 `//#region 常量与内部类型` / `//#region 读取与校验` / `//#region 帧转换与帧数学` / `//#region 导出解析器` 分区保持不变。

**`readHeader(data: DataView): IAnimationHeader | null`**

- `data.byteLength < ANIMATION_HEADER_SIZE` → `logger.error(82, data.byteLength.toString(), ANIMATION_HEADER_SIZE.toString())`，`return null`。
- `data.getUint32(0) !== ANIMATION_SIGNATURE` → `logger.error(83, signature.toString(16), ANIMATION_SIGNATURE.toString(16))`，`return null`。
