1. **`Scroll` 虚拟滚动被打穿**：`book` / `bookDetail` / `equipbox` / `toolbox` / `hotkey` 里，`Scroll` 的直接子元素常被每行 `container` 包住，甚至 `Scroll` 外还套一层 `container`。本渲染系统的 `container` 会创建画布缓存层，`Scroll` 只能按「直接子元素」逐个测量与显隐；每行一个容器意味着 `Scroll` 只看到单个大子元素，画面外不渲染的优化退化成整块显隐，同时加深缓存层级、放大内存压力。
2. **临界信息被整项隐藏**：`book` 的「伤害 / 临界 / 减伤 / 1 防」与 `bookDetail` 的「加攻 / 减伤」在 `critical` 为 null 时整项消失，用户无法区分「没有数据」与「数值为 0」。
3. **`bookDetail` 特殊属性长描述重叠**：`TextContent` 未取实际高度，每行固定 44 像素，长描述会压到下一行。
4. **条件渲染让元素反复挂载/卸载**：多处用 `{cond && <...>}` 表达显示开关，反复创建销毁渲染元素，既浪费又不利于命中区域稳定。

**做法（用户决定，不得扩大）：**

- **`book.tsx`**：四项临界信息恒渲染、缺失显示 `0`；每行改为「透明 `g-rect`（点击打开详情）+ `icon` + 11 个 `text`」共 13 个 `Scroll` 直接子元素，绝对定位，上层元素 `noevent`；根容器不加 `nocache`。
- **`bookDetail.tsx`**：删除每行 `container`，标题 `text` + `TextContent` 直接进 `Scroll`；`TextContent` 用 `autoHeight` + `onUpdateHeight` 上报真实高度，`specialRows` 一次遍历累加出每行位置；因 `TextContent` 只在挂载时复制 `props.loc`，每个 `TextContent` 的 `key` 由 `code` + `textTop` + 实测高度构成，位置变化时重挂载；`specials` 变化或切换模式时按 `code` 重建高度表；`加攻` / `减伤` 恒渲染、缺失 `0`；根容器不加 `nocache`。
- **`equipbox.tsx`**：删除描述区 / 装备槽区 / 拥有装备区三个外层 `container`，`Scroll` 与相邻文本直接定位在根容器；状态行 / 槽位 / 拥有装备行全部平铺；7 处显示开关按位置分流（`Scroll` 外 4 处 `hidden`，`Scroll` 内 3 处动态空文本 / 0 回退）；拖拽起手、悬停槽位、再点使用语义保持（命中矩形较原整格内缩 2-4px）。
