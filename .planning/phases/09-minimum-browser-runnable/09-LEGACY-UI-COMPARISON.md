# Legacy UI 功能对照：book / bookDetail / equipbox / toolbox

**用途**：逐项对照 `legacy-ui` 与当前实现，快速确认哪些没做、哪些已确认不做。
**状态**：只读对照，不代表已确认的问题；功能取舍以用户回复为准。
**对照范围**：`book` 主列表、`bookDetail`、`equipbox`、`toolbox`。`hotkey` / `settings` 暂未列入。
**legacy 基准**：`book.vue` 取 `7428f41^`（该文件在 `f53f611` 前已被删除）；其余取 `f53f611^` 的最后版本。

## 状态图例

| 状态 | 含义 |
|---|---|
| `无` | 当前没有该功能，需要实现 |
| `部分` | 原部分完成；按用户最新决定，全部归入不做 |
| `有` | 当前已有，维持现状 |
| `有（纯文本）` | 当前已有，且按决定维持纯文本，不实现 legacy HTML |

| `有（bug）` | 当前存在但已知有缺陷；不是精确 `无`，本批不执行 |
