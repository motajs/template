# 高级教程总导览

高级教程写给有高度定制需求、并且愿意理解引擎设计的作者。到了这一层，问题不再是「这个接口怎么调」，而是「这个需求该放在哪一层、该由谁在什么时机执行」。弄错这一层，效果可能当下能跑，却会在存档、读档或录像回放时对不上。

本层按难度分成 I / II / III 三层；分层是难度标签，不是领域分类，具体主题可能在层间调整。这一页说明三层的定位与主题、怎么选阅读路径、需要哪些前置，以及本层与中级教程的分工。

## 三层结构

| 层级                            | 定位                                   | 主要主题                                                                                                   |
| ------------------------------- | -------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| [高级 I · 扩展基础](./i/)       | 较低门槛，核心是插件系统与基本扩展机制 | 声明式接口、插件系统、可存档内容、录像一致性、data-common 的 Store、钩子深入、移动 Mover、FaceHandler 系列 |
| [高级 II · 深入定制](./ii/)     | 中等门槛，需要理解并修改引擎的特定系统 | 范围对象、图块、装备、录像指令、寻路、勇士与怪物属性、战斗上下文                                           |
| [高级 III · 原理与架构](./iii/) | 最高门槛，系统讲解设计原理与架构       | 双端分离约束、数据端 L0–L3、编辑器识别协议、录像深层原理、性能与调试                                       |

高级 I 是入口层，插件系统是这一层的核心，后面的可存档内容、录像一致性、data-common 的 Store 与钩子深入都建立在它提供的扩展位置上。高级 II 按主题深入单个系统，进入前应当先读完高级 I 的相关篇目。高级 III 讲的是支撑前面两层的原理与架构，已可阅读，入口见[高级 III 导览](./iii/)。

## 怎么选阅读路径

- <strong>先 I 后 II、III 按需</strong>：默认路径是从高级 I 顺着读，把插件、存档、录像与钩子这四块打通；遇到需要改造某个具体系统时再进高级 II，想弄清背后设计时再进高级 III。这条路径适合第一次系统扩展数据端的作者。
- <strong>按目标跳读</strong>：已经有明确需求时，可以直接按主题跳到对应层。例如要新增一套带存档的系统，从高级 I 的插件系统与可存档内容读起；要新增录像指令或自定义寻路，直接进高级 II；要判断某个约束为什么存在，再查高级 III。跳读时如果对某个接口的日常用法不熟，先回中级教程补齐。

## 前置

高级教程假设你已经读完中级教程，尤其是下面三篇：

- [数据端与渲染端](../intermediate/data-vs-render.md)：理解「算」与「画」的分工，以及为什么录像验证只跑数据端；
- [代码基础](../intermediate/code-basics.md)：类、接口、模块与类型的基本写法；
- [数据插件](../intermediate/data-plugins.md)：插件是什么、怎么注册、生命周期大致如何。

中级教程里的数据端总览、钩子、录像指令等篇目也会在具体页面里被直接引用；遇到不熟悉的接口时，回到对应中级篇目即可，本层不重复解释。

## 与中级教程的分工

中级教程讲「怎么用」：调用哪个接口、参数怎么填、常见的改法是什么。高级教程讲「怎么扩展」：新增的系统该放在哪一层、由谁在什么时机执行、怎样与存档和录像保持一致。同一件事在两层的深度不同，读高级时默认你已经会使用相关接口，因此这里只讲扩展点、取舍与边界，不重新罗列基础用法。

## 边界与注意

- <strong>渲染端内容</strong>：渲染端尚未完工，本层当前只收录数据端内容；渲染端专题只用占位标记指出归属，待完工后补上。
- <strong>编辑器内容</strong>：涉及编辑器与内容配置的部分只保留占位，不在本层展开。
- <strong>不重复中级已讲内容</strong>：接口的日常用法、参数清单与常见改法属于中级教程；本层只在需要说明扩展点时引用，不整段重写。
- <strong>高级 III 入口</strong>：该层已可阅读，入口见[高级 III 导览](./iii/)。
