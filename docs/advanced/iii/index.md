# 高级 III 导览

高级 III 是高级教程的最高难度层，讲数据端系统的原理与架构：这些系统为什么这样拆分、数据在它们之间怎么流动、哪些约束不能打破。它面向已经能独立改动数据端、现在需要判断改动该落在哪一层的作者。

这一页说明这一层是给谁的、与高级 I 和高级 II 的区别、需要哪些前置、收录了哪八篇，以及两条阅读路径。本层只写数据端；渲染端原理不在当前范围。

## 高级 III 是给谁的

- 你能读懂类、接口、泛型、装饰器与 TypedArray，不需要逐行解释也能跟上类型签名；
- 你需要判断一个改动该落在状态、系统还是加载层，而不是只把效果调出来；
- 你要排查存档与回放不一致的问题，需要知道状态从哪里来、由谁装配、什么时候写入；
- 你愿意先理解机制再动手，接受「顺序固定」与「不要重排装配」这类约束。

## 与高级 I、高级 II 的区别

高级 I 讲扩展机制怎么用：插件、存档、录像一致性与钩子各自怎么接。高级 II 讲具体系统怎么改到自己的需求：范围、图块、装备、寻路、属性与战斗上下文。高级 III 讲这些系统为什么这样设计、数据怎么流、失败会在哪里出现。

三层是难度标签，不是领域分类：同一主题可能在不同层以不同深度出现。读高级 III 时默认你已经会使用相关接口，因此这里不重复调用步骤，只讲结构、顺序与边界。

## 阅读路径

- **原理线**：CoreState 组装与初始化 → 插件内部机制 → 事件系统 → Anon-Tokyo 解释器 → 通行性谓词与寻路原理 → 录像系统底层 → 加载系统。适合想一次把数据端的结构与数据流打通。
- **按需线**：先读 CoreState 组装与初始化，建立分层与加载管线的心智模型，再跳到与当前问题最相关的一篇。每篇都单独成立，不需要按顺序读。

## 本层不覆盖什么

- 渲染端的结构性内容：渲染场景、绘制流程与客户端主对象属于渲染端，本层只写数据端；
- 编辑器与内容配置：编辑器属性项、地图事件 id 绑定与序列化事件注册由编辑器负责；
- API 签名清单：本层只讲机制与取舍，不罗列接口参数；
- legacy 包：旧引擎实现只作为对比基线出现，不作为扩展入口。

## 怎么验证你读懂了

- 能说出 CoreState 的四层装配顺序，并解释为什么不能重排；
- 能说明插件依赖成环或缺失时，为什么下游也会被阻断；
- 能解释事件为什么按「点事件整组在前、图块事件整组在后」的顺序执行；
- 能说出通行性谓词为什么会有两个实例，以及怎样让两侧保持一致；
- 能说明录像为什么能按步号读取，以及读取流为什么会过期；
- 能画出加载的三段阶段，并说清额外配置与自定义任务各自该在什么时候追加。
